# 卡面模板（W13，美术方案 A2）

状态：READY（主 agent，2026-11-17）。依据：美术方案 A2 与示意图 `docs/proposals/img/2026-11-16-art/W2-card-face.png`；检查点 ② 的 CP2-1（对局布局）与 CP2-3（默认稀有度三色）；卡面短文与细则（W10 已入配置）；[PLAY_LAYOUT](PLAY_LAYOUT.md) 的文字规则；[THEME_SPEC](THEME_SPEC.md)。

## 1 范围

- 一个绘制入口画所有卡：对局卡排、商店货架、战利品页、结算背景、“全部 N 件”列表。道具、服务、骰面改造、新骰子在商店里也用这个模板。
- 非目标：商店的分区与布局（W14），战利品页与结算的布局（W15），手册的卡牌页（W16）。这些工作包调用本模板，不另画卡。

## 2 三种尺寸

同一套代码按矩形大小与模式出三种尺寸。单位为 1080p 设计单位，720p 等比缩小。

| 尺寸 | 用在 | 自上而下 |
| --- | --- | --- |
| 商店 Shop（220×348；150% 文字 220×364，W14 E1） | 商店货架、战利品页 | 顶部宝石（跨在上边框正中）；卡名；方形插画（右上附魔角标，左上数值角标）；短文（完整显示）；价格按钮 |
| 桌面 Table | 对局卡排 Full 模式（约 210×244）、结算背景 | 左上序号圆片；顶部宝石；卡名；插画（角标同上）；短文。计分时的“+N / ×N”弹字仍在卡的右上方（W11） |
| 紧凑 Compact | 对局卡排 Mini 与 Text 模式、列表 | 方形图标块（用 W13a 的裁切图标，带稀有度边框）；右侧卡名；放得下时加短文；数值角标在图标块左上 |
| 紧凑货品行（W14 E2） | 商店“升级与服务”（452 宽）、“骰子与骰面”（448 宽） | 紧凑尺寸加价格按钮：图标块（新骰子放真实 3D 骰子，牌型升级放手册里的点数示例）；类别行与名称；放得下时加短文；右端价格按钮（“升级与服务”180 宽，150% 文字 184；“骰子与骰面”150 宽），60 高，原因长时两行（原因一行按 19.5 排，150% 文字时按钮最高 93） |
| 图块 Tile（W14 E3） | 商店“我的构筑” | 约 100×104（150% 文字 100×116）：图标块（稀有度边框，宝石在块底内侧）在上，卡名一行在下；序号圆片左上，附魔角标右上；不放短文与数值角标（悬停与详情有） |

- 文字：卡名 22 粗体，短文 20，下限 19.5（AX-03，720p 13 px）；数值角标 16–18。沿用 `Line11`、`NoWrap11`、`FrameInsets11`（字放在卡面贴图画出的边框以内）。
- 短文在商店与桌面尺寸里必须完整显示（TX-03，含 150% 文字）；紧凑尺寸放不下时不显示，悬停与详情里有完整内容（与 W11 相同）。

## 3 稀有度

- 边框颜色加顶部宝石，颜色取色板 `rarityCommon / rarityAdvanced / rarityRare`（默认 B8C9C5 / 55B6D9 / AD92DB，CP2-3）。卡面上不再写“常见 / 进阶”字样和刻度；悬停与详情仍写稀有度名称。
- **宝石形状随稀有度变化**：常见圆形、进阶菱形、稀有六角星。与示意图的偏离（示意图三者都是菱形）：进阶蓝与稀有紫明度接近，色觉差异的玩家只靠颜色分不清；形状不同才做到“一眼可辨”。
- 非卡牌的商品（道具、服务、骰面改造、新骰子）没有稀有度：边框用 `ghost` 色，不放宝石，卡名上方写类别（道具 / 服务 / 骰面改造 / 新骰子）。

## 4 角标与状态

- 附魔：插画右上角，沿用现有五张 `badge_enchant_*`。
- 数值角标：成长值、当前倍率等数值放在插画左上角（例：`×1.5`、`+12`、`当前 红`）。内容取现有状态文字（`CardTableState11`、`Art07OfferState`）中的数值部分；“技能详情”“点击查看条件”这类非数值文字不显示。它取代 W11 卡面的状态行和旧商店卡的页脚。
- 失效（首领减益“缴械”“凡人”等）：整卡压暗，数值角标位置改写“本关失效”，颜色用 `Danger`（现有逻辑沿用，只统一位置）。

## 5 价格就是按钮（商店尺寸）

- 价格按钮占卡底一行：金币图标 + 价格 + “购买”。买不起或不能买时按钮禁用，按钮上写原因（还差 N / 卡牌已满 10 张 / 卡牌栏位已满 / 道具栏已满 等，取 `Art07Availability07`，W14 起与商店同一来源，见 SHOP_LAYOUT 6；“需选择目标”取消）。
- 按钮至少 60 单位高，画面与点击区相同（W14 E1，与对局画面同一规则，720p 下 40 px）。
- **按钮用次级样式，不用强调色**：AX-02 要求每个阶段只有一个强调色按钮，A3 也写明商店里只有“下一关”用强调色。与示意图的偏离（示意图的购买按钮是金色）：价格数字与金币图标用 `Gold`，按钮面用 W11 的实底次级样式。
- 战利品页的同一位置是“领取”按钮（W15 决定样式）。

## 7 紧凑图标

- W13a 的裁切表 `DicePrototype/Assets/Resources/IconCrops/<风格>.json`（schema `icon-crops-1`）是来源记录；游戏读的是**离线烘焙的图标**：`DicePrototype/Assets/Art/Art11/Icons/<风格>/icon_<ID>.png`，160×160 RGBA，由 `tools/art_v11/crops/make_crops.py` 从原图高质量缩小，逐字节可复现（协调者 2026-11-17 决定：插画导入没有 mipmap，运行时裁切后画到 32 px 会出噪点，也省去运行时解析 JSON）。
- 查找顺序：当前风格的图标 → 默认风格的图标 → 整张插画。按（风格，id）缓存，换风格时清空（与 W11c 清空对比度缓存同一处）。
- 裁切不好的 id 由 W13a 列出，走 artgen 编辑另出图标图（不在本包内生成）。
