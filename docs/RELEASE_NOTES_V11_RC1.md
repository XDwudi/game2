# 骰子构筑 V1.1 试玩候选版

**macOS 下载已更新（修复版 r2）**。首发包在应用签名后加入了七份字体许可和说明文件，macOS 可能因此提示文件已损坏。修复包已将它们纳入签名。如果你下载过首发包，请重新下载并解压新版。该试玩包使用临时签名，尚未通过 Apple 公证，Finder 首次启动待真机确认。修复包 SHA-256 为 `6563468883172950f5863f74478199a08f1dfa4cfbb7fee456c3543ae14ed0be`。[下载 macOS 修复包](https://github.com/XDwudi/game2/releases/download/p1.1.0-rc.1/DicePrototype-p1.1.0-macos-universal.zip?revision=2)

同名卡牌现在可以同时持有。两张同名卡各占自己的位置，各自记录成长和附魔，也能单独出售。商店仍可能刷出你已持有的卡。刚买入的卡在离开这家商店前，卖价最高为当时的实付金额。

通关首领后会先打开战利品页。栏位已满时，可以先卖出腾位，再领想要的奖励。可领多件的奖励在取得第一件后就能进店，离店前还可以回来取余下的件数。也可以直接将整组未领的奖励折现。

## 画面与操作

- 在主菜单或暂停菜单进入设置，打开「画面风格」即可切换默认、瑞士现代主义、唐三彩陶坊、爆彩连环漫画、黑金装饰艺术和彩绘玻璃。风格选择会保留到下次启动。
- 每套风格都有自己的菜单托盘和六张首领奖励插画。结算单和领取页会显示同一件奖励的主题图，例如精研手册、骰面工坊和特制骰子礼盒。
- 桌面随八个章节逐步变换明暗。高压关有警示边，首领关带暗角。卡面显示效果短文，详情里可以读到完整条件。
- 关末结算单列出过关奖励、剩余提交奖励和利息，也显示结算前后的金币。「白干」首领会在达标前说明哪两项收入取消；结束按钮的悬停和实际结算分别列出「铁饭碗」和「赏金猎人」的收益。在对局中可以回看上一手的得分公式、每张卡的倍率和模仿链实际复制的卡。
- 商店的刷新、设置和手册按钮在悬停、按下和移开时，文字会随按钮面一起移动。

## 存档与启动

规则版本为 p1.1.0，存档格式为第 7 版。升级时会自动清理不兼容的旧版对局。新局照常自动保存，可以从主菜单继续。

- **Windows x64**　下载 `DicePrototype-p1.1.0-win-x64.zip`（886.5 MiB），完整解压后运行 `DicePrototype.exe`。
- **macOS Universal**　下载 `DicePrototype-p1.1.0-macos-universal.zip`（925.0 MiB），解压时保留整个 `DicePrototype.app`。此包同时包含 Intel 和 Apple 芯片架构，由 Windows 交叉构建，实机启动待验证。

遇到问题时，请附上关卡、风格、字号、操作步骤及「版本与构建」页中的信息。涉及卡牌或骰子时，同一帧里能看见牌名、骰面或得分明细的截图有助于复现。

结算时将指针停在奖励卡上，悬停框的上边缘会碰到红色说明后半行的底部 1–2 像素。金额和按钮仍完整可见，移开指针即可收起悬停框。

本次试玩采用 Unity 开发构建。卡面文字是否便于初次接触的玩家理解，以及缩小到四分之一的画面能否区分普通关与首领关，仍待真人验证。
