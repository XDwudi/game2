# W17 资源图标与界面用途

范围依据 [HANDOFF_V11 §3.5](HANDOFF_V11.md)、[SETTLEMENT_LAYOUT §8.4](SETTLEMENT_LAYOUT.md) 与 [PLAY_LAYOUT](PLAY_LAYOUT.md)。原计划的“约 12 个”是资源族估算。下表按当前正式画面的用途核算，每行列出实际载体，导航图标、内容插画与 W17 新增精灵分别注明。

| 用途 | 实际载体、风格与回落 | 玩家能看到的位置 |
| --- | --- | --- |
| 掷骰 | 现有 `ui_icon_roll`，默认与五套均有 | 对局“还能掷”预算，归零时同图减淡 |
| 提交 | W17 `ui_icon_submit`，默认白色透明，五套可覆盖 | 对局“还能提交”36 单位，结算“剩余提交”28／36 单位。两处均先找本风格再找默认。两者都缺时，对局画已有票券，结算文字左移 |
| 金币 | 现有 `ui_icon_coin`，六套均有 | 对局与商店余额、商品价格、折现与结算动效 |
| 利息 | W17 `ui_icon_interest`，默认白色透明，五套可覆盖 | 结算“利息”芯片，缺默认图时文字左移 |
| 过关／章节进度 | W17 `ui_icon_stage` 是结算“过关奖励”的旗帜。章节进度沿用六套 `ui_pip_dot`、当前点描边与章节数字 | 结算奖励、对局顶栏；章节说明不另设通用章徽 |
| 道具 | 按物品 ID 取本风格图，沿用 `ui_card_item` 卡框（六套）。紧凑内容图按 W22i 契约回落 | 对局道具格、商店“我的构筑”与道具详情 |
| 高压 | 已批准的状态色、目标数字、挑战选择和托盘细线 | 选关、对局本关牌与顶栏。选择普通挑战时按普通挑战显示 |
| 首领 | 七族内容徽记，六套共 42 张，另有四档 W17 边框。徽记按族及档位查找 | 对局本关牌、商店顶栏、结算与通关页 |
| 锁定／不可用 | 现有 `ui_icon_lock`，六套均有 | 对局道具不可用锁标 |
| 查看骰子 | 现有 `ui_icon_dice_view`，六套均有 | 对局“查看骰子”入口 |
| 手册／设置 | 现有 `ui_icon_book`、`ui_icon_gear`，六套均有 | 商店顶栏的两个导航按钮 |
| 刷新／继续 | 现有 `ui_icon_refresh`、`ui_icon_arrow`，六套均有 | 商店卡牌刷新与下一关、结算继续、战利品进入商店 |

**契约与计数。** W15 强制提供的 W17 默认资源图标为三张，目前五套扩展风格均使用默认回落。它们和既有 UI 精灵由 `UiKit.Template` 统一查找。既有导航精灵、紧凑插画、首领族徽与主题颜色各按原契约验收。通用道具符号、独立章节徽章、高压或通用首领符号及“约 12”中其他独立资源，仍缺已批准的具体消费位置，不能据此推算额外 PNG 件数。

**核对入口。** 精灵名及默认路径在 `tools/art_v11/theme_contract.json`，必需／可覆盖规则在同目录 `theme_contract.py`。对局、商店、结算的绑定分别在 `GameApp.Play11.cs`、`GameApp.Shop14.cs`、`GameApp.SettlementReceipt15.cs` 和 `SettlementRewardTerms15.cs`，首领绑定在 `GameApp.BossEmblem15.cs`。
