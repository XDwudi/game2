骰子构筑 P0 v0.72：高清简约美术测试版。请下载下方的 `DicePrototype-p0.7.2-win-x64.zip`，完整解压后运行 `DicePrototype.exe`。GitHub 自动生成的 Source code 压缩包是源码，不能直接运行。

## 这一版改了什么

- 界面件全部重做为边缘干净的高清矢量质感：纸卡、按钮、面板、内凹读数条、空槽、焦点框。
- 桌面换成与界面同一画法的平面木沿与毛毡，不再是写实木桌。
- 新的主标题字标与卡背。
- 卡牌缓慢呼吸，悬停时朝鼠标倾斜；主菜单字标浮动；毛毡上有一道很淡的移动光带。设置里打开“减少动态”后全部停止。
- 商店里的骰面预览改为圆角骰面和圆点。
- 玩法、数值、71 张内容插画和 3D 骰子与 v0.71 相同；存档通用（规则 p0.6.0 / schema 4）。

开发过程中先按最初要求做过一版像素风，用户看过后否决（观感发糊），该方向已全部撤掉，不在本包内。
