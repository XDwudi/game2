## 准备度与交界

- 规格/核心窗口/配置/测试已明确，规则可先行；工具链安装路径、许可、模板与输出需实测。
- 高风险：Roll先损坏再抽面；Submit先快照计分再复制/染色；最后一次达标优先；临时骰清理后耗尽；IO失败候选不可重算；C09买卖后重新检查研习资格。
- 验证顺序：配置及纯函数 → 事务边界 → 可玩第一关与商店 → 六关/内容 → 保存恢复 → 完整构建/视觉/性能。
- 独立评审分别给规格、制作质量与运行结论；没有执行不算通过。用户保留体验/美术和量产决定。
