## 这一版改了什么

依据用户 2026-11-12 的四张参考图（仓库 `docs/specs/v073/references/`）。玩法、数值、存档格式不变（规则 p0.6.0 / schema 4）。

- **商店**：取消五个标签页，改为一页分区：控制器卡牌、骰子柜台、消耗品、研究强化、骰面改造、商店服务同屏；价格在金色价签上；左栏显示下一关目标、永久骰和提交容量；底部“当前持有”列出骰子与道具；右下“下一关”。
- **骰子样式**：光滑面有釉面高光，粗糙面有颗粒，黄金面有受光的金边，玻璃骰是通透的蓝色；纹理与黄金按面生效。已锁骰子挂铜锁、坐在深色托盘上。控制器卡按附魔带彩色卡框。
- **高分动画**：一手得分达到本关目标的 50% / 100% / 200%（或总倍率达到 ×128 / ×1024 / ×8192）时，骰池上方弹出“高分 / 超高分 / 爆分”分数牌，分数滚动计数，显示连锁、倍率与算式，参与计分的卡牌打金色对勾。不延长结算时间，不阻塞操作。
- **查看骰子**：关卡界面右上角新增“查看骰子”。骰库列表、商店骰子柜台、“当前持有”里都是可以按住拖动旋转的立体骰子，不再平铺骰面；选面时按“面 1–6”让骰子转过去，或直接点骰子的面。骰库里新增“骰子样式说明”。
- **界面造型**：按钮、卡片、面板统一为阶梯切角；仍按原生分辨率绘制，没有低分辨率放大。
