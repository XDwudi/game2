## 范围内

1. **附魔出现率曲线**（规格 §9.1）：按商店周期取 `enchantRules.shopChanceByCyclePercent`；一张商店流整数票的抽法与区间顺序照规格；第 1、2 周期的低价保底卡固定无附魔且不抽票；非计分类卡的专池；L2、附魔台、点化不受影响。
2. **乘法卡同名去重**（规格 §9.3）：初始货架、刷新、扩栏、L1、L2 的候选过滤；购买与领取时的再验证；与本批次已有报价、保留组的关系。
3. **追赶值的发放**（规格 §5 第二段）：成长卡进入货架（初始、刷新、扩栏）或 L1/L2 战利品时，按生成商店的周期写报价的 `growthCatchup`；取得时原样继承、`growth` 从 0 开始；直接赠卡没有追赶。
4. **骰面改造**（规格 §7.1、§9.2）：
   - 按面的改造一次可选同一颗骰子的 1 或 2 个面（`maxSelectableFaces`）；整笔先验证再执行；执行顺序与随机变形的抽法；失败不扣金币、额度与随机状态。
   - **自选改造**：新命令（规格 §12.1 写作 `CustomDieUpgrade`），每店 `selfDieUpgradeLimit` 笔，加价 `selfDieUpgradePremium`，价格公式含砍价高手；`ShopState.selfDieUpgradeUsed`。
   - 镀金入口接入 W3b-1 的共用函数：商店的黄金电镀（货架、自选、铁匠铺赠礼、骰面工坊）、点金笔 I11、战利品 L5 的镀金骰。
   - 千锤百炼一笔成功交易只成长一次。
5. **牌型与颜色升级**（规格 §3.1、§9.2）：价格 = 基础价 + 当前等级 × `upgradePricePerExistingLevel`；上限 12；自选研习加价与额度照旧；L3 按实际可升级数结算；学无止境按实际升的级数成长。
6. **道具次数与钥匙串**（规格 §8）：`OwnedItem.usesRemaining`；I13 的取得、占槽、回收价、囤积居奇按一件算；`ItemUsed` 事件每次一个；物尽其用按次成长。
7. **解锁命令**（规格 §8）：`UnlockDie(targetDieId)`；选择来源的先后（回心转意的每手一次免费额度优先，否则库存最早的钥匙串）；徒手只挡道具；应用后的锁序与骰池位置；`HandState.unlockCardUsed`；不消耗投掷、不抽随机数、不触发再来三次的即时补发；重复请求返回原回执。给界面提供查询：当前能否解锁、会用哪个来源、钥匙串剩余次数。
8. **存档结构 8**（规格 §12.1）：版本号、规则版本、旧档门禁（行为与 p1.1.0 完全相同，只换版本号）；本包新增的全部字段进入克隆、序列化、读档校验、状态哈希、调试往返；新命令进入命令序列与请求去重。
9. **调试场景**：能构造钥匙串次数、自选额度、报价上的追赶值；调试候选池去掉已移除的卡、加入新卡与新道具。
10. **给界面与模拟器的查询接口**：自选改造的可选清单与实时价格、剩余额度；某个改造对某颗骰子哪些面合法；乘法卡是否因已持有而被过滤（供图鉴或提示用）；升级价。界面不应自己重算这些。
11. **测试**：
