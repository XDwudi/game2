## rc.2 相对 rc.1 改了什么

用户试玩 rc.1 后指出分数栏粗劣、边缘过渡不自然。这一版针对界面与动画细节返工：

- **桌面**：木沿从约 45 单位收窄到 17 单位，左侧计分板、分数栏、道具区和底部提示都落在毛毡上，不再压住木沿；沿下阴影改为柔和渐变。
- **分数栏**：最终分数放进读数窗；起作用的因子是实心色片（基础蓝，牌型 / 颜色 / 红组红，控制器金，附魔紫），×1 的因子只留描边。
- **左侧计分板**：改为有厚度的深色板；目标 / 累计 / 金币各在柔和凹槽里，带色键和加粗数字；“本关累计”旁新增进度条。
- **圆角统一**：提交槽、托盘、道具空位、待锁标记、关卡刻度和选中框都改为圆角环；“清除待选”“完整记录”和各标签页改为圆角描边按钮；底部提示改为停靠在底沿的标签。
- **动画**：读数变化时弹一下，进度条缓动，待锁金环缓慢呼吸。“减少动态”打开后全部停止。
- 玩法、数值、71 张内容插画和 3D 骰子不变；存档通用（规则 p0.6.0 / schema 4）。

逐项自评与仍未处理的不足见仓库 `docs/specs/v072/ART_SPEC.md` 第 5A 节。
