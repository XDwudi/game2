# V1.1 画面风格规格（THEME_SPEC）

状态：**骨架已实现**（W08，2026-11-16）；**风格接口补充已实现**（W20X，2026-11-17，`33d6d926`、`9d82b110`：`buttonStep` / `buttonStepPrimary`、`section`、`caption`、`Table/page_scene.png`，见 [W20X 报告](W20X_REPORT.md)）；**W20Xb 已实现**（2026-11-18，`6904b9c5`、`5dc03815`：桌面图按原尺寸导入，特效颜色在绘制时读色板，托盘三个标签都用 `caption`，见 [W20X 报告](W20X_REPORT.md) §10）；**W20Y 已实现**（2026-11-18，`05044756`：色板键 `buttonSecondary`，二级按钮 `SolidButton11` 的面色，见 [W20Y 报告](W20Y_REPORT.md)）。依据 [开发方案](DEV_PLAN.md) §4.6 与 G7。各风格的具体资源在 W12、W19–W23 中按本规格交付。

## 1 运行机制

- 默认风格内置在代码与场景里，就是 v0.73 以来的现有外观。其他风格放在 `DicePrototype/Assets/Resources/Themes/<风格 id>/`，启动时读取各自的 `theme.json`。
- 风格只改外观：色板、界面贴图、卡牌插画、桌面贴图、设置页预览图。布局、动效、规则、存档六套共用。
- 查找顺序：先找当前风格的同名文件，没有就用默认风格的同名件。贴图在第一次切到该风格时才加载。
- 设置项：
  - 设置 → 画面 → 画面风格，点一次换到下一套，立即重绘当前画面，不写存档；
  - 选择记在系统设置 `v11.theme`；
  - `theme.json` 里 `preview: true` 的风格还没做完，只在开发开关 `v11.themePreview = 1` 时出现，玩家看不到。
- 代码约定：
  - 颜色一律在绘制时读 `UiKit` 的属性（`UiKit.Panel` 等），不要存进静态字段，否则切换风格时这个元素不变；
  - 新界面元素用语义色：`Primary`（本阶段唯一的主动作）、`Reward`、`Boss`、`Pressure`、`RarityCommon / RarityAdvanced / RarityRare`。
- 代码位置：`UI/Theme/ThemePalette.cs`、`UI/Theme/GameTheme.cs`（含 `ThemeRegistry`）、`UI/GameApp.Theme11.cs`、导入规则 `Editor/V11ThemeImport.cs`。

## 2 theme.json

```json
{
  "id": "swiss",
  "displayName": "瑞士现代主义",
  "description": "一句话说明与依据",
  "order": 1,
  "preview": true,
  "palette": { "panel": "151515", "...": "..." }
}
```

`order` 决定设置里的顺序。按用户指令的顺序：瑞士现代主义 1、唐三彩陶坊 2、爆彩连环漫画 3、黑金装饰艺术 4、彩绘玻璃 5。

色板写 6 位或 8 位十六进制，省略的项沿用默认值：

| 键 | 用在哪里 | 默认 |
| --- | --- | --- |
| background | 页面底色 | 102A2D |
| felt | 桌布着色（桌面贴图会乘上它） | 173E40 |
| panel | 深色面板、按钮禁用底 | 203F43 |
| panelLight | 面板上的分隔与次级块 | 315358 |
| paper | 卡面、纸面按钮 | F4E8CB |
| ink | 纸面上的字 | 162629 |
| textColor | 面板上的字 | F7EED9 |
| muted | 面板上的次要字 | B8C9C5 |
| gold | 价格、高亮、现有的主按钮色 | F3BA58 |
| teal | 完成、正面状态 | 79C99C |
| red | 红骰、负面数值 | EC655D |
| blue | 蓝骰 | 55B6D9 |
| violet | 附魔与特殊 | AD92DB |
| danger | 错误、首领警示 | 9E3440 |
| shadow | 投影 | 07191C |
| ghost | 次要按钮描边 | 6A9296 |
| primary | 本阶段唯一的主动作按钮（W11 起使用） | F3BA58 |
| reward | 奖励时刻 | F3BA58 |
| boss / pressure | 首领关、高压关的标识 | C8463F / E0703A |
| rarityCommon / rarityAdvanced / rarityRare | 卡面稀有度边框（W13 起使用） | B8C9C5 / 55B6D9 / AD92DB |
| onFelt | 直接画在桌布上的标记：骰子握把的点、提交格序号、空提交格的点（W11b 起使用）。桌布浅的风格必须填深色 | 不填：各处沿用原色（握把 paper、序号 muted、空格点 panelLight） |
| valueBadge | 卡面数值角标（×1.5、+12、本手可用）的底色（W13 起使用） | 不填：沿用 gold |
| buttonStep / buttonStepPrimary | 按钮下方的台阶（`UiKit.Button`，次要 / 主按钮）（W20X 起使用，`33d6d926` 实现） | 不填：沿用 8F453A / B56B29 |
| buttonSecondary | 二级按钮的面色。二级按钮指 `GameApp.SolidButton11` 画的按钮：行动行的次要按钮、跳过演出、查看骰子、上一手明细、计分明细、商店里的按钮，以及卡面与商品行上的价格按钮。同一个值既落在桌面与深色面板上，也落在纸面上，所以要取两边都看得清的中间色（W20Y 起使用，`05044756` 实现） | 不填：沿用 `lerp(background, panel, .55)`，禁用时再向 `panelLight` 混 25%（现状） |
| section | 商店分区底板 `ui_section_panel` 的乘色。填了以后，骰子样式页的八个样例格也乘这个色，两处看起来一样（W20X 起使用，`33d6d926` 实现） | 不填：商店乘 `panel`，样例格不乘色（W14 现状） |
| caption | 标题条的乘色：商店分区标题条 `ui_section_header` 与骰子托盘上的标签（`PoolTab11` 由 W20X 实现，`33d6d926`；`PoolSummaryTab11`、`PoolPageTab11` 由 W20Xb 补上，三个标签看起来一样）。条上的字仍按实际底色自动选（下文 W11b 规则） | 不填：分区标题条乘 `panelLight`，托盘标签乘 `panel`（现状） |

乘色只会把贴图调暗：画出来的颜色 = 贴图颜色 × 乘色。贴图本身带颜色、要原样显示的风格，把对应的乘色填 FFFFFF。`buttonStep`、`section`、`caption` 三组是协调者 2026-11-17 为爆彩漫画审查定下的接口（漫画概念页的黄色标题条、蓝色分区），由代码任务 W20X 实现（`33d6d926`，2026-11-17 起生效）。`buttonSecondary` 是协调者 2026-11-18 为黑金与彩绘玻璃加的接口：两张概念页的次要按钮都是浅色牌子，现有的二级按钮在黑色桌面上几乎看不见（黑金 1.11:1）。已由代码任务 W20Y 实现（`05044756`）。禁用的二级按钮的字现在固定用 `muted`，在浅色面上只有约 1.6:1；W20Y2 改为按画出的面色用 LabelOn11 选字，首选 `muted`。

对比度要求（AX-08，按色板自动测量）：`textColor` 对 `panel`、`ink` 对 `paper` 至少 4.5:1；`muted` 对 `panel` 至少 3:1。

画在色块上的字（主按钮、算式筹码、总分筹码、关卡标签、本关牌标题等）由代码自动选色（W11b，`GameApp.Play11Contrast.cs`）：先按色块实际画出的颜色（贴图中心色 × 着色）在 `ink`、`paper`、`textColor` 中选对比度最高的一个，目标 4.95:1（AA 的 4.5:1 加 10% 余量，照顾细笔画的中文）；三者都达不到时，把色块按 5% 一档加深（或调浅）到达标为止。所以风格作者给出的强调色在带字的色块上可能画得略深，例如瑞士的 E80E16 画成 D10D16，默认的首领红 C8463F 画成 AB3D35。有含义的字色（如金币的金色）在达到 4.5:1 时保留。

`red` 与 `blue` 同时决定 3D 骰子的骰点颜色（`DiceTable` 读 `UiKit.Red` / `UiKit.Blue`）。骰点颜色是游戏最重要的功能提示，按 CP3-1“功能提示不变”，**每套风格都用默认这一对：EC655D / 55B6D9**（协调者 2026-11-17；瑞士与唐三彩已照此设置）。要改须有记录在案的用户决定。

关卡状态色是提示，不是装饰（美术方案 B2：高压关桌沿红色细线、目标数字用红色）。`pressure` 必须是一眼能认出的警示色，不能用中性灰；只有一种强调色的风格可以与 `boss` 同色（瑞士 E80E16，检查点 ② CP2-2），首领关另有压暗桌面、红框本关牌与徽记来区分。高压关的目标数字（顶栏目标、结算面板的差额）在所在底色上达不到 4.5:1 时保持色相，按 5% 一档调亮或调暗（取能提高对比的方向），最多 8 档；仍达不到才换成上面规则选出的字色（W11c）。

## 3 文件与尺寸

| 路径 | 内容 | 要求 |
| --- | --- | --- |
| `UI/<名称>.png` | 界面贴图，名称与默认件相同 | 与默认件**像素尺寸相同**，RGBA；九宫格边距、每单位像素沿用默认件（导入规则自动复制），所以边框必须画在默认件的边距带里 |
| `Art/illustration_<内容 id>.png` | 卡牌插画（按 D1 每套重画） | 1254² RGBA，经 `artgen` 生成并有记录；导入上限 1024 |
| `Table/felt_tile.png` | 桌布平铺纹理 | 1024²，可无缝平铺 |
| `Table/table_scene.png` | 整张桌面构图 | 1920×1080 |
| `Table/page_scene.png` | 非对局画面的桌面（可选，W20X 起使用，`33d6d926` 实现；模态框跟随其下的画面，各画面用哪张见 [W20X 报告](W20X_REPORT.md) §3） | 1920×1080。不提供时所有画面都用 `table_scene`（现状）。对局画面和画着对局版面的画面（如结算背景）始终用 `table_scene` |
| `preview.png` | 设置页预览 | 480×270 |

默认件清单由脚本生成：`python tools/art_v11/theme_contract.py contract` 读取 Bootstrap 场景里 `art07Templates` 的实际内容，写出 `tools/art_v11/theme_contract.json`。2026-11-18 重新生成：94 张，其中 50 张被代码按名称或名称前缀引用，另外 44 张没有代码直接引用，风格可以不提供。W14 的商店不再使用 `ui_price_chip`、`ui_pedestal`、`ui_frame_enchant`，所以这三张已转为没有引用。瑞士、唐三彩、爆彩漫画是在这之前做的，仍带着这三张，无害；黑金与彩绘玻璃不必画。

### 3.1 桌面构图（协调者 2026-11-17）

- `table_scene` 按对局版面（PLAY_LAYOUT §1）画。四个安静区保持纯色，最大偏差 0：骰区 52,374,1408,276；算式行 52,660,1408,60；提交栏 344,740,1136,202；提交说明 32,740,360,202。
- 大块装饰（放射线、爆炸框、大色块）只放在任何对局状态都不压界面的地方。会变的区域：
  - 卡牌栏 32,96,1448,244：空栏位缩成 56 宽的“+”条；全尺寸卡最多 7 张，约到 x 1350；8 张起改为紧凑两行，铺满整行；
  - 行动行 32,956,1858,100：按钮随状态变化，放装饰前按 W11 代码逐个状态核对。
- 装饰不能被直线裁切：每条射线以尖端结束或整圈描边，只有画出来的面板边缘可以截断装饰。装饰也不伸进按钮、面板的外接矩形，否则会从切角里露出碎片。
- `page_scene` 是商店、选关、卡牌详情等非对局画面的背景。它不对应任何版面，所以不放会被面板切碎的大块装饰。W20X 列出了非对局画面里直接画在桌面上的字（`tools/art_v11/table_text.json`）。协调者 2026-11-18 决定：非对局画面不把字直接画在桌面上，每行放到面板或标题条上。不改用“桌面上的字”色，因为在爆彩漫画这类有图案的页面上，任何单一字色都不够清楚。主菜单与选关由 W16 处理，整局结束页由 W15 处理。验收用 `python tools/art_v11/table_text_contrast.py <风格>`，每套风格每处都要达到 4.5:1。
- 桌面图（`Table/table_scene.png`、`Table/page_scene.png`）按原尺寸导入，不缩放到 2 的幂，与默认桌面一致。W20X 发现 `V11ThemeImport` 原先把它们缩放到 2048×1024：画面被压扁，上下各约 60 行露出 `_BaseColor`×0.24 的底色，静区与界面错开。由 W20Xb 修正。

## 4 源文件与检查

- 界面件生成器：`tools/art_v11/<风格 id>/`，沿用美术流程“界面表面件与九宫格用脚本矢量”的路线。GPT 生成的纹理与插画的原图、记录放在 `ArtSource/Art11/<风格 id>/`。
- 检查：
  - `python tools/art_v11/theme_contract.py audit <风格 id>`：多余件、尺寸不符、缺透明通道判为失败；被引用却没有提供的件列为 FALLBACK；
  - 发行前用 `--strict`：FALLBACK 也算失败，除非在该风格的说明里写明理由；
  - 实机截图（F-THEME-02）与色板对比度（AX-08）。

## 5 已知局限（骨架阶段）

- 一些界面把字直接画在桌布上，用的是浅色的 `textColor` / `muted`。浅色桌面的风格（瑞士现代主义）会看不清；W11 改版时让这些字都落在面板上，或者增加“桌面上的字”色。W20X 在运行的游戏里列出了非对局画面上的这些字（`tools/art_v11/table_text.json`，19 处：主菜单 2、选关 15、整局结束 2），检查器 `tools/art_v11/table_text_contrast.py`；低于 4.5:1 的，按 §3.1 放到面板或标题条上（W15、W16）。
- 商店分区：W14 起底板乘 `panel`、标题条乘 `panelLight`，只有一种样式；W20X 已增加 `section`、`caption`（`33d6d926`）。
- 按钮台阶色已改为 `buttonStep` / `buttonStepPrimary`（W20X，`33d6d926`）。W20X 排查了全部写死的颜色（18 个文件 50 处，口径见 [W20X 报告](W20X_REPORT.md) §5）：两处特效固定色（`Art071EnchantCue`、`Art071ComboEdgeAccents`）与计分爆点是默认风格的颜色存在静态字段里，没有随风格变。协调者 2026-11-18 决定改为绘制时读色板（W20Xb），这也是 §1 的代码约定：附魔提示读 `teal` / `violet` / `paper`，连锁边饰读 `gold`，计分爆点读 `gold` / `red` / `blue`。默认风格的值相同，画面不变。W20Xb 已实现（`5dc03815`，不再有静态颜色字段；PlayMode `PLAY_W20XB_B` 核对）。其余写死的颜色（进度槽、遮罩、失败印章、手册行底色、副标题色等）保持，暂不加色板项；黑金或彩绘玻璃需要时再加。
- 所有画面共用对局桌面，`table_scene` 里按对局版面画的东西会出现在商店等画面的缝隙里（爆彩漫画的蓝色桌布块与射线最明显）。W20X 已加 `page_scene`（`33d6d926`）。
- 字体还不随风格变（W21）。
