## 2. 新机制

### 2.1 提交快照新增字段

提交冻结时写入，计分只读快照：

| 字段 | 含义 |
| --- | --- |
| `rollsUsed` | 本手已投掷次数（含遥控骰子的那次投掷），≥ 1 |
| `submissionsRemainingBefore` | 本次提交之前，本关剩余的提交机会，≥ 1。等于 1 即“本关最后一次提交机会” |
| `permanentDiceCount` | 冻结时玩家拥有的永久骰数量（不含临时骰），≥ 0 |
| `poolDice[]` | **留池骰**：冻结时存活、本手已投出、没有锁进提交栏的骰子，按创建序号升序。每项：`dieId`、`faceId`、`currentPip`（含遥控覆盖）、`currentColor`（物理面颜色） |

留池骰包含存活的临时骰，不包含本手已碎裂的骰。留池骰使用自己的当前点数与物理面颜色，不受不要奇数、首当其冲、红色浪潮影响。

每颗提交骰另有四个由冻结的六面数据推出的属性（没有六面数据的合成快照一律视为不满足）：

| 属性 | 定义 |
| --- | --- |
| 当前面纹理 | 朝上那一面的 `texture`（`smooth` / `rough` / `none`） |
| 整骰同色 | 六个面的物理颜色全部相同 |
| 整骰同点 | 六个面的永久点数全部相同 |
| 对面点数 | 朝上那一面的对面（F01↔F06、F02↔F05、F03↔F04）的永久点数 |

### 2.2 成长值（M1）

每个控制器实例的动态状态新增 `growth`（非负整数，初始 0）与 `saleBonus`（非负整数，初始 0）。

- **乘法成长卡**：倍率 = (20 + growth) ÷ 20，即 growth 以 0.05 为单位。
- **加法成长卡**：整手基础分 + growth。
- 成长发生在触发它的那次计分**之后**；该次计分用成长前的值。
- 成长只发生在真实持有的实例上，每个实例每次事件只成长一次。百变模仿复制成长卡时，使用被复制实例的当前成长值参与计分，但不另外成长（与人员流动一致）。
- 卖出、替换、损毁即失去成长值；商店里的商品成长值为 0。

### 2.3 再计一次（M2）

每颗提交骰有一个再计次数 r（默认 0，各来源相加）。
逐骰贡献的计算方式不变；**点数合计 = Σ 贡献 × (1 + r)**。再计不改变牌型、红组、骰子数量，也不重复触发任何“每颗骰”的条件。

### 2.4 牌型倍率加值（M5）

> 牌型倍率 = max(×1, 同点牌型倍率 + 顺子倍率 + 牌型倍率加值)

### 2.5 计分顺序（完整）

1. 有效点数与有效颜色（不要奇数、首当其冲、红色浪潮）——不变。
2. 牌型、顺子、主牌型、颜色牌型——不变。
3. 红组：按现有规则在提交骰里分组，取最大组（数量多者优先，同数量取分组键大者）。场外红人生效时把留池红骰数量加进这个组的数量。
4. 判定每个来源是否触发（第 4 节各卡的“触发”）。
5. 逐骰贡献：有效点数 → 各来源的加值（顺序无关）→ 飘忽不定 ×3 → 始终如一 ×2 → 玻璃 → 黄金。
6. 点数合计 = Σ 贡献 × (1 + 再计次数)。
7. 基础分 = 点数合计 + 未用投掷奖励 + 现有整手加值（对穿肠、有钱真好、有也不交、稳稳分数）+ **新整手加值**（成长加法卡、板凳深度、厚积薄发、越挫越勇、天生一对）+ 基础分附魔。
8. 得分 = 基础分 × 牌型倍率 × 颜色倍率 × 红组倍率 × 各控制器倍率（按控制器从左到右）× 倍率附魔，最后向下取整一次。
9. 计分后计划：现有项不变，新增成长变更（第 4.1 节）。

## 3. 栏位、货架与服务

- 普通栏位是每局状态：开局 5，购买“扩充栏位”+1，上限 7。免槽附魔的控制器不占普通栏位。总件数上限 10。
- **O08 扩充栏位**（服务）：价格 8 + 6 × 此前购买次数（8、14），整局最多 2 次；受道具折扣影响，最低 1。普通栏位已到 7 时不再出现。
- 每家商店的服务报价从 1 项改为 2 项（从合法服务里不重复抽取）。
- 控制器货架开局 4 件；“增加控制”仍把上限扩到 6（因此最多可买 2 次）。
- 商店抽卡完全随机（按稀有度权重），不看玩家已有的卡。首件保底规则不变（第一件报价是未持有且基础价 ≤ 4 的卡）。

### 4.9 连带规则

| 问题 | 规则 |
| --- | --- |
| 百变模仿复制新卡 | 复制完整技能。成长值、卖价加成与被复制实例共用且不重复成长；祭坛的摧毁只由真实的祭坛执行；被动数值类（再给一次、多交一手、双刃剑、铁饭碗、利滚利、以战养战、砍价高手、聚宝盆）按来源数叠加 |
| 提交次数下限 | 多交一手、双刃剑、提交附魔合计后，每关提交次数最少 1 |
| 投掷次数 | 每手投掷次数 = 3 + 投掷附魔数 + 再给一次来源数 + 本关道具加成 |
| 祭坛的结算时点 | 开始关卡时、冻结控制器顺序与模仿绑定之前，按从左到右依次处理每个真实祭坛；被摧毁的祭坛不再行动；最右侧的祭坛没有目标，不成长。摧毁不是卖出，不触发人员流动 |
| 以战养战的比较对象 | 本关当前目标（选了高压则是高压目标）；先计分、再发金币，金币不回算本手 |
| 聚宝盆的卖价加成 | 加在半价回收之后；成长基金 / 百变模仿的基金累计照旧另加 |
| 砍价高手与附魔加价 | 先合计“基础价 + 附魔加价”，再减，最低 1 |
| 利滚利 | 本金上限 = 25 + 25 × 来源数；存钱罐等其它利息规则不变 |
| 熟能生巧、玻璃心与本手 | 投掷和碎裂当场成长，所以本手的投掷 / 碎裂在提交冻结前已经计入 |
| `rollsUsed` 的范围 | 本手每一次投掷都算，包括再来三次、投掷附魔、道具给的额外投掷和遥控骰子 |
| `permanentDiceCount` 的范围 | 冻结时仍然存活的永久骰；本手已碎裂的不算 |
| 以战养战的上限 | “每关 2 次”是触发次数，不分来源；每次触发按来源数发金币 |
| 祭坛吃掉的价格 | 被摧毁卡的基础买入价，不含附魔加价；右邻不论是否免槽、是否百变模仿都会被摧毁 |

## 6. 关卡目标

第 1–11 关沿用 p0.8.0。第 12–24 关以 v0.8 实测备选数值为起点（38,000 … 4,000,000），在 50 张新卡、5–7 栏位全部接入模拟器后重新校准。

高压目标 = 普通目标 × 1.25，高压奖励 +3，不变。
