## 检查器能说明什么

- 当前文件是否与声明的内容哈希相同，是否缺失、为空或指向根目录之外。
- 选定的上游副本是否保留了清单内的原始文件和许可证。
- 给定 NUnit 报告的用例明细、结果、数量及必要测试名称是否满足严格检查条件。

它不能证明清单覆盖了所有依赖，不能判断报告是否由可信进程产生，不能认证真正的审核人，不能保证测试断言合理，也不能判断游戏好不好玩。实际使用仍需要可信运行来源、任务追溯和独立复核。

- 目标设备的性能、触控、暂停恢复与实际体验。
- CI、远端分支保护、独立凭据和不可绕过的合并限制。
- 整个多 agent 制作流程在真实游戏任务中的遵守情况。
