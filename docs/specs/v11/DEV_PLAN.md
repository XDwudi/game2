### 4.3 卡牌重复获得（G3）

1. 同名控制器卡可以同时持有多张。每张是独立的一件：占自己的栏位（附魔“不占栏位”照旧）、各自记成长值与状态、各自出售。
2. 商店货架、首领战利品（稀有控制器、附魔控制器两种）都不再排除已持有的卡。同一个货架上不会同时出现两张同名卡，这是“抽样不放回”，和是否持有无关。
3. 购买同名卡不再替换旧卡，也不再用旧卡的卖价抵扣。“同名控制器只能替换为不同附魔”这条规则取消。
4. 效果按张叠加：倍率相乘、加值相加，计数方式与现在“百变模仿复制出来的来源”相同。写明“持有时”生效的开关类效果（例如 C140 回收大王）多张也只生效一次。150 张逐张核对叠加方式，写入 `RULES_DELTA.md`。如果发现会无限刷钱这类漏洞，先停下问你。
5. 平衡只测量：同一机器人、同一批种子，重复获得前后各 300 局，报告通关率与强度变化，供你决定是否调目标。

### 4.4 首领战利品先领（G5）

1. 顺序：首领关结算 → 点“继续” → 全屏的“首领战利品”页 → 选好后进入商店。
2. 选法不变：按种类可以拿 1–3 件，或者整组折现 5 金币。必须二选一才能进商店；折现总是可选，所以不设“跳过”。
   - 实施中的调整（2026-11-16，协调者决定，可改）：可拿多件的战利品（L4 骰面工坊、L6 道具补给各 3 件），领取第一件后商店就解锁，其余件数离店前仍可在商店里领取，离店时作废。原因：要求一次拿满 3 件时，道具栏只有 2 格的玩家必须先卖掉道具；用户要的是“通关后直接选”，不是每件都强制领取。
3. 栏位满时，战利品页上可以直接出售已有的控制器或道具腾位置，价格与商店相同。
4. 规则实现：商店仍在“继续”时生成；战利品组没领完或没折现之前，规则拒绝商店里的购买、刷新、研习和离开，只允许领取战利品和出售。读档时如果停在这一步，回到战利品页。
5. 商店右上的“首领战利品”按钮在战利品领完、折现或离店后取消；可拿多件的战利品领了第一件之后，商店里保留一个“首领战利品（还可领 N 件）”入口直到领完或离店（规则见第 2 条的调整）。杂货郎、铁匠铺的“商店赠礼”留在商店里。
6. 终局首领通关直接胜利，不变。

### 4.5 旧存档（G6）

1. 启动读档时，活动存档或备份的配置版本、存档结构与当前不同：删除活动存档、备份、以前留下的旧版保留副本（`*.legacy-schema*`），不弹提醒，主菜单显示“暂无存档”。
2. 当前版本的存档损坏：维持现有处理（回退到备份，或者显示存档读取说明），不删除文件。
3. 调试分区同样处理。设置、按键、风格选择存在系统设置里，不在存档里，不受影响。
4. 取消的界面：主菜单的“旧版本存档”按钮、旧档说明弹窗、“保留备份并开始新局”。

切换方式：设置 → 画面 → 画面风格，六选一，带预览。主菜单和对局中（暂停 → 设置）都能换，立即生效，不影响对局状态和存档。选择记在设置里，重启后保持。缺某件贴图时回落到默认风格的同名件，并计入缺件检查（F-THEME-02）。

### 4.7 性能放宽的边界（第 8 条）

- 全部测试照常运行。功能、规则、可见性类的失败必须修。
- 只属于“性能与资源”类的失败（帧时间、加载耗时、内存、包体、资源诊断），记录为“按用户 2026-11-16 第 8 条暂缓”，不阻塞 rc。不删测试、不改阈值，在任务记录与 STATE 里逐条列出，最终版本确认后处理。哪些测试属于这一类，在任务记录里逐条认定。
- 新风格的贴图本版不做按需加载与压缩优化。

### 5.3 分工原则

- **主 agent（我）**：范围、依赖、文件所有权与集成；所有 Unity 编辑器操作（串行）；界面代码；构建与交付。
- **子 agent（Claude）**：边界清楚的独立模块（规则、模拟器、参考实现、配置文字、界面件生成器）和只读复核。同时最多两个重型子 agent（v1.0 曾因并行过多三次触到用量上限）。子 agent 不启动 Unity，规则改动用 .NET 宿主自测，Unity 测试由主 agent 跑。
- **Codex**：
  - 图像生成（经 `artgen`，后台串行，逐张核对参考图确实传入）；
  - 独立复核里“另一种模型”的视角（只读沙箱）；
  - 个别边界清楚的脚本任务（独立 worktree）。
  Codex 和图像生成共用同一份 ChatGPT 额度，编码类任务从严使用。
- **文件所有权**：上表“可写路径”就是锁。同一场景、Prefab、全局设置同时只有一个写入者。`docs/STATE.md` 只由主 agent 写；其他会话写的小节不改动。
- **集成**：子 agent 交付后由主 agent 合并、跑 Unity 测试、看实机截图。新界面一律先看截图再算完成：v1.0 有两处界面缺陷测试全过，只在打包版截图里被发现。
