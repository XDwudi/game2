## 这一版改了什么

规则版本 p0.9.0 / 存档结构 5。界面与美术沿用 v0.73，新增 51 张卡面插画。完整规则见仓库 `docs/specs/v09/RULES_SPEC.md`。

- **50 张新控制器**（共 100 张），八个家族：成长型、再计一次、留池骰、投掷阶段、牌型专精、骰面协同、经济、牺牲与取舍。
- **五个新机制**：成长值（卡随对局变强）、再计一次（指定骰的贡献再算一遍）、留池骰（没提交的骰子也有用）、投掷次数相关的卡、牌型倍率加值。牌型手册新增第三页说明。
- **能拿更多卡**：普通栏位 4 → 5，新服务“扩充栏位”最多加到 7；货架 3 → 4；每家商店 2 项服务。总件数上限仍是 10。
- **后半程目标上调**：第 12 关起更高，最后一关 1500 万。前 11 关不变。
- **高分动画**只看这一手占本关目标的比例（过半 / 达标 / 两倍）。
- **祭坛**每关开始时会摧毁右侧相邻的卡：商店里目标卡有红框，关卡预览页会写出将被摧毁的卡名，可以先拖动调序。

存档：旧版本进行中的对局不能继续，进入游戏会提示并让你开始新局，旧文件保留，设置不受影响。
