### 第二、三轮结果

- r02：13 次运行全部有效。实施者把 r01 与 r02 并排看过（`artifacts/cache/v10/art-contact/r02_compare.png`，不入库），并统计了尺寸、透明度与留边：
  10 张可用；**3 张仍有问题**，做了第三轮：
  - C104：仍是 1536×1024。r03 把三颗骰子改成斜向紧排，得到 1254×1254。
  - C111：金色占 17%（黄色药瓶），超出已交付插画的范围（最高 10.4%）。r03 在主体里写明药瓶是红色和蓝色，金色降到 5.8%。
  - C140：画面有一层半透明的浅色底（alpha 1–32 的像素占画布 25%，`lightFringeShare` 0.86），顶边贴边。r03 用同一主体重抽，浅色底消失（1.1%）。
- r03：3 次运行全部有效，都是 1254×1254，在纸色底与毛毡底上各看过一次（`r03_check.png`，不入库）。
- 选用：49 张 r01、10 张 r02、3 张 r03（`manifest.json`）。**62 张全部是 1254×1254**，kit 均为 style-kit-1.1。
- 第二、三轮之后仍然带 LOOK 标记、实施者选择接受的：
  C149（透明占比 81%：斜放的弯刀本身很细，主体宽度已到 83%）；C134（主体宽 62%，竖长的瓶子）；C140 r03（主体宽 55%，回收桶是竖长物件）。
  另外 C106 r02 左右留边只有 15 px（主体宽 98%），C111 r03 底边 12 px；主体完整，没有再重抽。
- 实机图册（流程 S5 的替代证据）：`PLAY_ART071_FullArtGalleryRendersAll71ThroughProductionViews` 把每个内容用正式的卡面视图、176 px 与 64 px 图标分别渲染在毛毡底与纸底上。
  入库后的截图在 `evidence/v10/art/ingame/1080-art/` 与 `720-art/`（各 14 页，覆盖第 104–184 项内容）。它是资产检视画面，不是对局画面；对局中的截图见 Windows 包回放（`evidence/v10/screens/`）。
- 第二轮独立复核：见 `evidence/v10/art/ART_REVIEW_R2.md`（只覆盖改动过的 13 个 ID 与实机图册）。

## 没有处理、留给用户决定的

复核报告 §8 列了 14 个需要美术方向决定的问题，实施者没有替用户决定。影响面较大的：

1. 锚点与 kit 仍是 PROPOSED；本批以它为基准。
2. 植物能否用绿色（C115 无心插柳、C152 草根逆袭是黄绿 / 青绿，已交付的 C36 有先例）。
3. 红骰 / 蓝骰的标准画法（彩色点、侧面涂色、整颗上色并存；第二轮新做的 C104 用了总纲写明的“彩色点”）。
4. 竖长主体的宽度下限；同一颗骰子相邻两面同点是否要管；I10 与 I01 是否做成一对；U09 是否要画出“去掉一个点”；I08 的撕纸边是否认可为主体例外。
5. C151 留白底边只留 8 px（主体完整，未重做）；C123、C124 的 MINOR 项未动。
