启动：Windows 完整解压后运行 DicePrototype.exe，保留 Data 和 DLL。macOS 保留完整 DicePrototype.app；Universal 包含 arm64+x86_64，M5 使用同版验收工具包测试原生运行、Metal 和新目录封装，Intel 实机运行单独待验。

24 关构筑挑战，初始金币 0。先投掷、点选待锁骰、确认锁定，再提交全部已锁骰；确认锁定后默认不能普通解锁。拖动提交骰改变顺序，右键打开骰子详情。详情中分开查看永久六面、当前结果与有效点数颜色；旋转预览、展开概率不改变游戏状态。
默认快捷键：R 投掷，1–9、0 选骰，L 确认锁定，Enter 提交，Backspace 清除待选，H 打开牌型手册；可在设置中重新绑定。输入框聚焦时不触发游戏快捷键。达标仍有次数时可继续本关，或结束本轮结算。

商店上方固定显示控制器报价，下方切换道具、研习、骰强、服务、骰柜五页。控制器可拖拽调序，进入关卡后顺序冻结。刷新只改控制器：首次 3 金币，每次 +2；免费首次服务对应 0、5、7……。买骰与提交容量独立；附魔、普通槽/持有总数、替换净价与出售价格以界面为准。替换和出售需确认。

牌型手册包含 14 个结构条目（13 个可强化牌型与散点），颜色单独一页。全红/全蓝只要求提交全部同色，无最低骰数，以独立乘区计算。手册另有重新查看引导和独立固定骰练习入口；练习不覆盖正式挑战。

设置分为声音、画面、辅助。声音分别调节主音量、音乐、音效、界面；辅助提供正常/快速/即时速度、减少动态、文字100/125/150%、颜色辅助与快捷键。跳过表现不会重抽或改变已保存结果。
显示可选择分辨率及全屏、无边框、窗口模式。应用后 15 秒内确认，超时或 Esc 恢复。未确认时异常退出，下次启动恢复上次稳定设置；偏好独立于 Run 存档。实际系统模式支持和已验范围以本版报告为准。

调试：在设置→辅助输入 XD is god，区分大小写且不加首尾空格。独立工作区可任意组合控制器与附魔、道具，编辑最多32骰、32控制器、32道具、32提交容量以及六面点数/颜色、当前结果、牌型/颜色等级。应用后运行测试手；纯预览不消耗随机数。普通挑战与练习保持隔离，调试成绩不能用于正常难度判断。
