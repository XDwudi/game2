# 骰子构筑 v0.71 开发交接包

本包用于已存在的 Unity 6.6 原型，Blender 5.2 负责骰子母模型。它包含美术改进方案、开发任务与图像样件，不是完整 Unity 工程，也不提供新的玩法配置。

## 阅读顺序

1. ART_BRIEF.md：短的共用风格说明。
2. references/battle_master_v071.png：对局视觉母版。
3. V071_PLAN.md：完整方案与资源规格。
4. TASKS.md：按顺序执行的 Codex 任务。
5. STYLE_TOKENS.json：映射到工程主题系统的起始参数。

PROMPTS.md 保存本次完整生图提示词，用于继续修改和衍生素材。references/shop_derived_v071.png 展示同风格如何迁移到商店。

## 如何给 Codex 使用

将本包置于项目可读目录，向 Codex 提供项目位置与 TASKS.md 的总任务。先完成素材和美术样板，再扩展全量页面。若现有技能或编辑器连接已可用直接沿用；没有连接时使用本地执行的编辑器构建脚本。不要为了本次美术调整同时安装多个连接器或迁移 UI 框架。

没有把 ART_BRIEF.md 安装成自定义 skill；它是可直接读取的项目说明。文中列出的 Unity 与 imagegen 技能按实际开发环境调用。
