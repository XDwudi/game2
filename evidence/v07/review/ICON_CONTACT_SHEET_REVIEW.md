# art0.7.0 71 图标独立联系表复核

v07_spec_audit 实际查看 `ArtSource/Art07/Previews/content_64px.png`、`content_32px.png`、`similar_content_comparison.png`，以及C07/C42原始256PNG。与权威manifest逐项motif对照。下面“主形吻合”只评价联系表里观察到的主体，不代表每一装饰细线、KRA源、三底色、实机材质或用户风格验收通过。

观察时的71导出SHA及联系表SHA见 `ui-scan/source-bindings.json`；被查看图像副本在 `ui-scan/images/`。32像素用于判断轮廓能否区分，不强求在该尺寸读出小数字/极细刻度；正式技能和倍率必须由卡片TMP说明补足。64像素是本轮主要形状核对尺寸。

## 明确返工与已修复项

- **ICON01 / C07：需返工。** 右骰仍是实填纸色，只有紫色边和较少点数，未体现“左实右虚”。建议右骰使用开放/虚线描片或半透明纸影，保留方形复写箭头；不能仅用不同点数暗示复制。已通知art，不改玩法。
- **ICON02 / C42：需返工。** 短炮和菱形折射线存在，但主体青蓝，无指定paper/danger色彩关系。建议纸色玻璃体、局部danger强调，保留短炮轮廓；不作整卡红闪。已通知art。
- **ICON03 / C35：本轮目视确认方向修复。** 当前左高右低，与C34左低右高相反；1/2/3保留。32像素数字不足以稳定逐字读，但两个倾向的轮廓可以区分。只确认PNG修正，不据此认定重导KRA/Unity资源已验。
- **ICON04 / C09、C46：UI拼装待补，不要求PNG烘焙倍率。** 当前徽章是乘号图形，四倍/三倍具体数字应遵循正文动态倍率由TMP显示的要求。实际默认卡摘要仅“点击查看条件”，需由root补相应固定倍率/动态值。这与C07/C42的图形缺项不同。
