- **UIS10 local challenge choice:** `ChoosePreview07` only updates UI fields. `StartPreviewStage07` sends the existing `ChooseChallenge` command if required, then sends `StartStage` only after an accepted, non-pending-save result. No RNG, reward, source binding, or core state write was added to the UI. The core still freezes controller order in `StartStage`. This is a sound source-level correction; real click/cancel/retry tests for this new interaction remain needed.
- **UIS08 qualified-stage explanation:** the sidebar and end-stage tooltip use `PreviewStageSettlement`, whose implementation returns a detached calculation/clone. Base reward, remaining-submission reward, interest principal, C01 continuing income and the non-refund warning are separate. No reward is credited by hover. An actual small-screen tooltip capture remains needed; its 688×376 design-space panel can clip long text at 150% because overflow is ellipsis.
- **UIS07 visible drag:** `DisplayDragged` moves the same die view; hit region is transparent and origin marker is a non-raycast outline. There is no clone of a playable die, rule mutation, or RNG call during movement. `CancelDieDrag07` clears `draggedDie07` before `Refresh`, so the refresh cannot recursively cancel itself. A normal cancellation refresh restores the committed ordering. The remaining drop and lifecycle defects below prevent closing UIS07.
- **Guide null hand:** `DrawGuide07` permits Shop but checks `ViewState.hand != null` before reading locked IDs. StagePreview and menu return before a hand-dependent guide path. `ShowGuide07` closing the modal before refresh is not itself a rule mutation or null-hand defect. The new shop test has an independent fixture error described below, so the shop behavior is not yet confirmed by that test.
- **UIS06 notice:** notice drawing moved to the action reason area rather than covering locked dice. Its text is non-raycast, and the timer holds for 2 seconds then fades for 0.2 seconds. Save errors remain modal and are not expired. The priority/lifecycle defect below remains.
- The new information tests actually passed invalid seed retention, structure-vs-chosen-item/zero reason, exact nine C53 branches with shared ownership/read-only state, and card price/rarity/tooltip information. The settlement information test did not reach the UI because its fixture was rejected.
