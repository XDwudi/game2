骰子构筑 v0.73 · 商店、骰子样式与高分动画试玩版（rc.1）


这一版改了四件事，玩法、数值和存档都没有变：

1. 商店改成一页：控制器卡牌、骰子柜台、消耗品、研究强化、骰面改造、商店服务同屏显示，
   价格在金色价签上，右下角“下一关”离开商店。点卡片看完整说明。
2. 骰子有了材质：光滑面有釉面高光，粗糙面有颗粒，黄金面有金边，玻璃骰是通透的蓝色。
   已锁的骰子挂铜锁、坐在深色托盘上。
3. 高分动画：一手得分达到本关目标的一半（或总倍率达到 ×128）时，骰池上方弹出大分数牌；
   达到目标、达到目标两倍时依次升级为“超高分”“爆分”。
4. 查看骰子：关卡界面右上角新增“查看骰子”按钮，打开骰库。骰库里、商店里的骰子都是可以
   按住拖动旋转的立体骰子，不再平铺骰面。按“面 1–6”让骰子转到那一面，也可以直接点骰子的面。
   骰库右侧的“骰子样式说明”把八种样式摆在一起。

界面的按钮、卡片和面板统一改成了阶梯切角，画面仍按原生分辨率绘制。

Windows：完整解压后运行 DicePrototype.exe，保留同目录的 DicePrototype_Data、UnityPlayer.dll 和其他文件。

macOS（Universal，Intel 与 Apple 芯片）：完整解压后保留整个 DicePrototype.app。
这个包是在 Windows 上构建和压缩的，没有开发者签名、没有公证，也没有在任何 Mac 上启动过，能否运行尚未验证。
系统很可能拦截首次打开。可在“终端”里依次执行（把路径换成你解压的位置）：
  xattr -cr DicePrototype.app
  chmod +x "DicePrototype.app/Contents/MacOS/DiceCraft P0"
  codesign --force --deep --sign - DicePrototype.app
然后右键 DicePrototype.app 选择“打开”。如果仍无法启动，请把提示文字和系统版本反馈给我们。

第一次游玩：点击“新建挑战”，确认种子与初始状态；投掷 → 点选待锁骰 → 确认锁定 → 提交。
确认锁定后，本手不能直接解锁。“继续对局”恢复最后一次成功保存的状态；已有存档时，新建会再次确认覆盖。
默认键位：R 投掷，L 确认锁定，Enter 提交，Backspace 清除待选，H 牌型手册，Esc 暂停或关闭弹窗。
右键骰池里的骰子也能打开骰库，拖动已锁骰可调整顺序。自定义键位以设置页为准。

如果不喜欢动画：设置 → 操作与辅助 → 打开“减少动态”。高分牌会变成静止的，骰子转面直接跳转，
商店里待售的骰子不再自转；拖动旋转不受影响。

存档与 v0.71、v0.72 通用（规则 p0.6.0，存档 schema4）。Windows 的位置在
%USERPROFILE%\AppData\LocalLow\XDwudi\DiceCraft P0。

本版做过的验证：完整 EditMode 与 PlayMode 自动测试（1920×1080 与 1280×720 各一轮）；
用 Windows 包在新目录启动并自动走完一段对局与商店。
本版没有做的验证：macOS 实机启动与运行、Windows 帧时间与独占全屏专项（v0.7 起即未通过，本版未重测）、
独立复核。风格与体验由试玩者判断。AudioMixer 总线仍未接入，声音使用分类音量回退；高分动画没有专属音效。
