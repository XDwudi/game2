骰子构筑 v0.8 · 平衡性更新试玩版


这一版只改数值和几条规则，界面、美术和操作方式与 v0.73 相同。

改了什么：

1. 关卡目标：第 1 关从 180 提到 300，前三关略高；第 5 关以后比以前低，后半程每关稳定上涨，
   最后一关 150 万。难度不再集中在中段，而是越往后越难。
2. 金币：利息改为每 5 金币 1、每关最多 5；牌型升级涨得更快，但每家商店可以自选研习 2 次；
   控制器卖出能拿回标价的一半。
3. 控制器：大倍率卡整体下调并涨价（例如玻璃大炮 ×10 → ×5，大数开路 ×7 → ×4 且条件更严），
   稀有卡出现得更多；几张冷门卡加强（顺子倍率 6 → 10，66 大顺、小头大用、红蓝相当等）。
   控制欲改为每件控制器算 0.5 倍；人员流动每家商店只成长一次；错乱乘积的结果改为 0.5 到 5 倍。
4. 骰子：玻璃骰贡献 ×3、每次投掷 8% 概率碎裂（原来 ×2、15%）。

具体数值见游戏内每张卡的说明；完整清单在源码的 docs/specs/v08/RULES_DELTA.md。

存档：v0.8 的规则版本是 p0.8.0，旧版本（p0.6.0）的进行中对局不能继续，
进入游戏会提示旧存档并让你开始新局，旧文件会保留。设置不受影响。

Windows：完整解压后运行 DicePrototype.exe，保留同目录的 DicePrototype_Data、UnityPlayer.dll 和其他文件。

macOS（Universal，Intel 与 Apple 芯片）：完整解压后保留整个 DicePrototype.app。
这个包是在 Windows 上构建和压缩的，没有开发者签名、没有公证，也没有在任何 Mac 上启动过，能否运行尚未验证。
系统很可能拦截首次打开。可在“终端”里依次执行（把路径换成你解压的位置）：
  xattr -cr DicePrototype.app
  chmod +x "DicePrototype.app/Contents/MacOS/DiceCraft P0"
  codesign --force --deep --sign - DicePrototype.app
然后右键 DicePrototype.app 选择“打开”。如果仍无法启动，请把提示文字和系统版本反馈给我们。

第一次游玩：点击“新建挑战”，确认种子与初始状态；投掷 → 点选待锁骰 → 确认锁定 → 提交。
确认锁定后，本手不能直接解锁。“继续对局”恢复最后一次成功保存的状态；已有存档时，新建会再次确认覆盖。
默认键位：R 投掷，L 确认锁定，Enter 提交，Backspace 清除待选，H 牌型手册，Esc 暂停或关闭弹窗。

试玩时特别想听的反馈：
- 哪一关开始觉得吃力，哪一关觉得太轻松；通关或失败时停在第几关。
- 钱够不够花，有没有攒了一堆却没东西可买的时候。
- 哪些卡你觉得太强、太弱或者没人会买。
- 高分动画出现得是多是少。倍率下调之后，最高一档（爆分）比以前难触发。

本版做过的验证：完整 EditMode 与 PlayMode 自动测试；规则模拟器与游戏计分逐次对拍；
用最终数值让机器人打了 300 局记录难度与金币曲线。
本版没有做的验证：真人试玩、macOS 实机启动、Windows 帧时间与独占全屏专项、独立复核。

完整身份见游戏内“版本与构建”。
