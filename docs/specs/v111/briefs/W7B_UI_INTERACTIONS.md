## 要做的事

1. **按面的改造一次选两个面**（§7.1）：现有选面界面（`GameApp.ShopFacePick14.cs` 一带）支持在同一颗骰子上选 1 或 2 个面（上限读 `MaxSelectableFaces(upgradeId)`；U05 不选面，U11 恰好 1 个）。哪些面可选读 `LegalUpgradeFaces`；确认前用 `PurchaseErrorForFaces`／`CustomDieUpgradeError` 取拒绝原因并显示。价格不因面数变化。预览同时展示两个面改造后的样子。换骰子时清空已选面。
2. **自选改造**（§9.2）：商店里加入口，显示“自选改造 剩 N 次”（`CustomDieUpgradesRemaining`）。打开后列出 `CustomDieUpgradeOptions()` 的 11 种改造：名称、效果短句、实时价（已含自选加价与砍价高手）、不可买时的原因（额度用完、金币不足、没有合法目标、战利品未领）。选一种后进入与货架改造相同的选骰选面流程，确认时发 `CustomDieUpgrade`。成功后刷新剩余次数。入口的位置与样式沿用现有“自选研习”（牌型升级的自选）的做法，两者并列、风格一致。
3. **钥匙串与撤回已锁骰子**（§8）：
   - 道具栏里钥匙串的图标上显示剩余次数 1–3（`OwnedItem.usesRemaining`）；详情写明用法。点它的“使用”不再发 `UseItem`（会被拒），而是提示“点一颗已锁定的骰子来撤回”，并让可撤回的骰子有可见的提示状态。
   - 对局里，当 `UnlockQuote(dieId).available` 为真时，已锁定的骰子可以被选中并出现“撤回”操作；操作上写明这次用的是哪个来源：“回心转意（本手免费）”或“钥匙串（剩 N 次）”（`UnlockView.sourceId`、`keyRingUses`）。点击后发 `UnlockDie(dieId)`。来源由规则决定，界面不提供选择。
   - 不可用时不出现操作；若玩家持有钥匙串或回心转意但当前不能撤回，悬停／选中已锁骰子时给出原因（`UnlockView.error`：徒手、本手免费次数已用且没有钥匙串、还没掷骰等）。
   - 撤回会消耗钥匙串次数、不可撤销：不需要二次确认弹窗，但操作必须是明确的按钮，不能是点一下骰子就直接生效。
   - 撤回后的演出：骰子从锁定区回到骰池原规则规定的位置（会话状态为准），其余已锁骰子保持顺序；`DieUnlocked` 与 `ItemUsed` 回执各有一条文字记录；钥匙串用到 0 次时图标消失、道具槽腾出。
   - 回心转意（C154）卡面上显示本手免费次数是否还在（`UnlockView.freeAvailable`）。
4. **纪录**（§13 第四行、§12.1）：
   - 结算页与通关／失败的整局结果页显示“本局最高单手”与“最高过关倍数”（`RunState.highestHandScore`、`highestClearRatioNumerator/Denominator`，显示成“×3.2”，一位小数、向下取）；本关刷新了最高单手时有标记（`handRecordBroken` 或回执 `HandRecordBroken`、`ClearRatioRecord`）。
   - **历史最高单手** `historicalHighestHandScore`：保存在局外的正式记录里（不在 `RunState`，调试局不计入）。先看现有的局外存储（设置、统计、`AtomicSaveStore` 一带）怎么存别的局外数据，沿用同一套机制与原子写入；旧记录文件没有这个字段时按 0。每次正式局里刷新本局最高单手、且超过历史值时更新并落盘。主菜单显示“历史最高单手”。读写要有 EditMode 测试（含旧文件兼容、调试局不写入、损坏文件不崩）。
5. **得分演出分档**（§13 第五行）：现有的高分演出按固定分数分档的，改为按本手冻结的有效目标 `T`：`< T` 无这三档，`[T, 3T)`、`[3T, 10T)`、`[10T, +∞)` 各一档；`T` 取提交时的有效目标（含高压与首领对目标的调整）。先找出现有分档逻辑与它的测试（W7a 备注提到 `HighScore073`、Burst 夹具），在其上改，不另起一套。
6. **玻璃提交后碎裂的演出**：把现有的碎裂演出（`BreakDie07`、轮廓、12 片上限）接到提交之后的节拍上（回执 `DieBroken` 现在出现在提交回执里）。W7a 在 `TEST_CHANGES.md` 里登记了四处因此暂时去掉的检查（位置、轮廓、片数上限等），在提交路径上补回来。
7. **W7a 留下的小项**（见 `W7A_NOTES.md` §5）：养成卡在卡面与栏位计数行上的“不占栏位”标识；加成明细条目很多时的收起／展开；演出里“加成”事件相对乘法卡的先后（应在乘法卡之前结算显示，与公式顺序一致）；调试面板加道具时钥匙串给 3 次（`usesRemaining`）并可设置次数。
8. **回放工具**：`Core/Session/Validation~/NormalRunSearch.cs`、`NormalRunReplay.cs` 的命令镜像补上 `upgradeId`、`targetFaceIds` 与两个新命令；`tools/replay_v11.py` 及游戏内回放入口同理（只做到“含新命令的记录能被正确重放”，不扩展功能）。

   - 每个新交互都有 PlayMode 测试走真实界面路径（点击入口、选骰选面、确认、断言会话状态与界面文字）：双面改造成功与一合法一非法被拒、自选两笔后入口变灰、钥匙串 3→2→1→0 与图标消失、免费撤回优先、徒手下的原因提示、撤回后骰子位置、纪录显示、三档演出各触发一次、玻璃提交后碎裂。
