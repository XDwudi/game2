# 骰子构筑 V1.1.1 试玩候选版

这一版是平衡性更新，计分结构和大部分卡牌数值都改了。旧版的对局不能继续，需要开新局。

计分多了一行「加成」。颜色、黄金面和大多数卡牌给出的加成先相加，再整体乘一次；只有少数卡仍是真正的乘法。多一张或少一张卡不再让分数相差好几倍，首领让一件卡失效时损失也小得多。得分明细里可以展开加成的每一项。

## 颜色与卡牌

- 全蓝、全红改为加成，红组从三颗起算。不刻意凑颜色也能打出接近最优的分数。
- 真正的乘法卡面值多为 ×2.5–×3，几张高倍卡下调（大数开路、双刃剑 ×4→×3，玻璃大炮 ×5→×4）；加成卡和基础分卡普遍加强。牌型等级上限为 12，升级更便宜。
- 成长卡不再设上限，长得更快。连庄、老当益壮、祭坛三张稀有倍率成长卡改为从 ×1.25 起长；连庄换了牌型只把长出的部分减半，不再回到 ×1。骰面养成卡大约四到五关就能成型。
- 抛光匠、纹理大师、客串明星、小头大用保留名字和插画，换成了新效果。
- 移除玻璃心、吹玻璃、防碎膜。玻璃骰改为提交计分之后才可能碎。新增三张卡：回心转意、状元插金花、绝地反击。

## 商店与道具

- 每家商店可以自选两次骰面改造，一次可以改同一颗骰子的两个面。镀金面更容易掷出，黄金面的效果改为加成。
- 新道具「钥匙串」可用 3 次，每次把一颗已锁定的骰子撤回骰池，可以重掷或再锁定。持有回心转意时，先用它每手一次的免费撤回。
- 附魔出现的机会随章节提高，前期少、后期多。

## 首领、目标与纪录

- 「凡人」改为让最左侧一件稀有卡失效；「万籁俱寂」从三件减为两件。
- 每关目标分重新设定：前三关降为 160、320、500（原为 300、600、1000），末关为 700 万（原为 2000 万）。中段最紧，后期放松，成型构筑可以打出远高于目标的分数。
- 单手达到目标的 1 倍、3 倍、10 倍会有不同的庆祝演出。关末结算页显示本局最高单手和最高过关倍数，主菜单显示历史最高单手。

## 存档与启动

规则版本为 p1.1.1，存档格式为第 8 版。升级时会自动清理不兼容的旧版对局并提示。新局照常自动保存，可以从主菜单继续。

- **Windows x64**　下载 `DicePrototype-p1.1.1-win-x64.zip`（890.9 MiB），完整解压后运行 `DicePrototype.exe`。
- **macOS Universal**　下载 `DicePrototype-p1.1.1-macos-universal.zip`（929.4 MiB），解压时保留整个 `DicePrototype.app`。此包同时包含 Intel 和 Apple 芯片架构，由 Windows 交叉构建，使用临时签名，尚未通过 Apple 公证，实机启动待验证。

## 已知问题

- 商店「升级与服务」里，「全蓝」牌型升级那一行的等级与加成说明在默认、唐三彩主题下不显示，在其他主题下「加成」会被断到两行；150% 字号下「全红」那一行也可能不显示。把鼠标停在该行上，提示框里有完整说明。
- 部分首领减益仍然偏重。模拟对局里，终局的独木桥、万籁俱寂、釜底抽薪等会让得分降低八成以上；万籁俱寂在调整卡牌顺序后仍会降低六成多。强度会根据试玩反馈再调。
- macOS 访达「显示简介」里的版本号显示为 1.1.0，以游戏内「版本与构建」页的 p1.1.1 为准。

遇到问题时，请附上关卡、风格、字号、操作步骤及「版本与构建」页中的信息。涉及卡牌或骰子时，同一帧里能看见牌名、骰面或得分明细的截图有助于复现。

本次试玩采用 Unity 开发构建。新数值只经过模拟对局校准，真人手感、各流派之间是否平衡仍待试玩验证。
