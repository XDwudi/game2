# 骰子构筑 P0 v0.73 美术资源方案

配套文档：[版本策划方案](VERSION_PLAN.md)。参考图在 `references/`。

## 1. 方向

- 沿用 v0.72 的配色（深青桌面、纸色卡、墨线、红 / 蓝 / 金 / 紫强调色）和高清字体。
- 新的造型语言来自参考图：**阶梯切角**、**深色厚底座**、**斜切标题带**、**金色价签**。
- 所有素材由脚本用矢量形状绘制，4 倍超采样后缩小，边缘锐利，不模糊、不低分辨率放大。
- 需要着色的素材画成白 / 灰，由代码按语义上色（和 v0.72 相同）。

阶梯切角规格：每个角切两级台阶，每级 6 参考单位（PPU 200 下 12 像素）。九宫格边距 40 像素不变，所以现有布局代码不用改边距。

## 2. 生成与接入

| 项 | 内容 |
| --- | --- |
| 生成脚本 | `tools/art_v073/build_art.py`，确定性，重跑覆盖全部文件 |
| 校验脚本 | `tools/art_v073/verify_assets.py`：文件清单、尺寸、透明通道、重新生成后逐字节一致 |
| 输出目录 | `DicePrototype/Assets/Art/Art073/Surfaces`、`/UI`、`/FX` |
| 导入 | `V073Setup.Integrate`：复用 v0.72 的导入设置（Surfaces：PPU 200、边距 40；其余 PPU 100、无边距、无压缩、无 mipmap），按名字替换 `art07Templates` 中的同名素材并追加新素材 |
| 回退 | v0.72 素材目录不动；撤销 `V073Setup` 的场景改动即可回到圆角版本 |

### 3.4 立体骰子（着色器与程序网格，不是贴图）

| 项 | 做法 |
| --- | --- |
| 骰体网格 | 沿用 `dice_body_bevel`（Blender 导出），不改 |
| 陶瓷体 | 沿用 `DiceCraft/Art07/Ceramic` |
| 玻璃体 | 同一着色器的玻璃分支调整：底色改为清澈的蓝（约 `#4FA9E6`）；新增一遍背面渲染让内部轮廓可见；边缘高光由墨色改为亮青白 |
| 骰面图层 | 新着色器 `DiceCraft/Art073/Face`：受主光照明、支持顶点透明度。每个面一张程序网格，按“点数 × 镀金 × 纹理”缓存 36 种 |
| 光滑面 | 面上铺一层略亮的釉色圆角片 + 两条斜向高光带 |
| 粗糙面 | 面上固定分布约 48 个深浅斑点（固定随机种子，同一种面永远相同） |
| 黄金面 | 四边金框加宽到 0.06，朝光两边亮金、背光两边暗金，四角有小亮点 |
| 点数 | 沿用凹陷珐琅画法 |

所有新增几何避开点数保护区，不影响点数辨认；红 / 蓝只出现在点上。

## 5. 动效

| 编号 | 动效 | 时长 | 减少动态 |
| --- | --- | --- | --- |
| M8 | 高分牌弹入（缩放 0.86 → 1.04 → 1） | 120 ms | 无缩放，直接出现 |
| M9 | 分数滚动（缓出） | ≤ 420 ms | 直接显示最终值 |
| M10 | 放射条向外伸展、火花外飞并淡出 | 与本拍等长 | 不显示 |
| M11 | 高分牌淡出 | 160 ms | 120 ms |
| M12 | 骰子“转到某一面” | 180 ms | 直接跳转 |
| M13 | 按钮按下：面下沉到底座 | 沿用现有按钮动效 | 沿用 |
| M14 | 商店待售骰子缓慢自转（约 12 秒一圈，拖动后停止） | 持续 | 静止 |

## 6. 关于 Blender

本版不需要新的立体模型：骰体网格沿用；骰面差异全部由程序网格和着色器表达，这样纹理、镀金才能逐面生效并和规则数据一一对应；挂锁、纸签、托盘前沿是屏幕空间素材（要盖在骰子旁边而不是被桌面透视压扁）。因此 Blender 5.2 本版不调用。

## 7. 不做的事

- 不重画内容插画，不引入像素字体，不做整屏像素化或抖动。
- 不改桌面背景、字标、卡背。
- 不新增音频。

## 8. 验收

- `verify_assets.py` 输出清单与本文件 §3 一致，重新生成逐字节相同。
- 实机截图在 1920×1080 与 1280×720 下核对：切角台阶清晰、无拉伸变形、九宫格边角不被缩放。
- 八种骰子样式放在同一张实机截图里可分辨（对应参考图 3 上半部分）。
