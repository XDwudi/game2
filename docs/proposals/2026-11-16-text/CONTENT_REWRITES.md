## 2. 写法约定（本提案统一采用，供审阅）

- 卡面短文一句“条件 → 效果”，目标 ≤ 28 字；边界情况放“细则”。两者合起来等于原规则。
- 按用语规范：去掉“有效”；“整手得分×3”写“得分×3”；“整手基础分+10”写“基础分+10”；“点数贡献+10”写“每颗计分+10”；“提交栏容量/K”写“提交栏 N 格”；“钱包/余额”写“金币”；“背包/道具槽”写“道具栏位”；“研习”写“升级”。
- 规范未覆盖、本提案暂用的词（见第 4 节待决）：再计 N 次（手册已有“再计一次”词条）、留池骰（手册与对局界面已用“留池”）、主牌型、散点、成长型卡的“得分倍率从×1起 / 基础分加成从+0起”、封印、失效、红组。
- 稀有度用界面实际显示的“常见 / 进阶 / 稀有”（GameApp.Art07Shop.cs:39），而不是文本里的“普通 / 罕见”。
- 数字区间写“1~3点”，倍率写“×1.5”，概率变化写“+15%（如50%→65%）”。
- “1颗”“1次”用阿拉伯数字；“第一颗”“最后一颗”保留汉字序数。

## 4. 术语冲突与待决

### 4.1 需要用户决定的命名

1. **“控制器”是否改名。** 现名像工程用语，商店标题还写成“控制器卡牌”。候选：
   - “卡牌”：最直白，和商店现有标题一致；缺点是牌型（一对、顺子）也叫“牌”，“牌型倍率”“卡牌倍率”容易混。
   - “护符”：被动、可装备的感觉，和“附魔”“破咒符”同一语境；缺点是道具里已有“破咒符”“扩容符”两种“符”。
   - “法宝”或“秘籍”：有中文游戏味道，不与现有词冲突；缺点是风格比现在的“复古印刷骰桌”更偏武侠。
   - 保持“控制器”：改动最小，所有文本与手册不用动。

2. **“提交”是否改为“打出”。** “提交”像表单；“打出”贴近“出牌”。代价：C79“多交一手”、C48“有也不交”、C21/C22/I06“增加提交 / 大量提交”的名字都以“交 / 提交”为梗，需要一起改；“提交栏”要改成“出牌栏”之类。另一候选“出手”（“本手出手”略拗口）。建议先定词再动名称。
