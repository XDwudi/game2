骰子构筑 v0.71 · 主菜单与桌面更新试玩版


这一版加入了根据 Image2 概念制作的纸质主菜单，以及木沿、金色缝线和深青毛毡桌面。卡牌与三颗真实陶瓷骰组成新的开场画面；71 项内容插画和现有玩法继续保留。

Windows：完整解压 Windows x64 包，运行 DicePrototype.exe，保留同目录全部 Data、DLL 与其他文件。建议先用默认窗口模式试玩。
Mac：完整解压 macOS Universal 包，保留整个 DicePrototype.app。Mac 实机运行、Metal、签名与公证尚未完成验证。若下载的是 MacVerificationKit，它已包含游戏；按“执行说明.md”运行，无需另下 Mac 包。

第一次游玩：点击“新建挑战”，确认种子与初始状态；投掷 → 点选待锁骰 → 确认锁定 → 提交。确认锁定后，本手不能直接解锁。“继续对局”恢复最后一次成功保存的状态；已有存档时，新建会再次确认覆盖。
默认键位：R 投掷，L 确认锁定，Enter 提交，Backspace 清除待选，H 牌型手册，Esc 暂停或关闭弹窗。右键查看骰子详情，拖动已锁骰可调整顺序。自定义键位以设置页为准。

设置提供文字大小、颜色辅助、减少动态和演出速度。请反馈页面、种子、分辨率、文字比例、复现步骤及截图；涉及控制器时，附上控制器顺序和附魔。
