骰子构筑 p1.1.0 试玩版

Windows x64
请完整解压，然后运行 DicePrototype.exe。程序会从同一目录读取 DicePrototype_Data、UnityPlayer.dll 和其他游戏文件。

macOS Universal
请完整解压，保留整个 DicePrototype.app。这个包面向 Intel 与 Apple 芯片，采用 Windows 交叉构建。Mac 实机启动未验证，未经 Developer ID 签名或公证，系统可能会阻止打开。

第一次游玩
主菜单选择“开始新的一局”。进入对局后，掷骰，点选要保留的骰子，锁定，再提交牌型。可以从“牌型手册”查看牌型与计分。已有本版进行中的对局时，主菜单的“继续对局”可以恢复进度。

规则版本为 p1.1.0，存档格式为第 7 版。报告问题时，请附上系统、关卡、操作步骤，以及“版本与构建”页里的技术信息。

字体版权与许可证收录在 Licenses 文件夹内。macOS 应用包内的 Contents/Resources/Licenses 也保留同一份文件。
