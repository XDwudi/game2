## 1 请求批准的构图

**推荐用一只浅托盘，把现有的四张牌与三颗陶瓷骰子摆成同一组。** 主标题在左上方，卡牌在托盘后半部，骰子在前；玩家从字标读到牌骰，再到右侧的“开始新的一局”或“继续对局”。托盘的近侧边缘和接触阴影把牌骰放回桌面，后沿收低。画面要看得见牌上的画、骰顶的点和各自的外形。托盘内部大面积留空，彩色重点让给两张卡插画与主按钮。

原美术提案的 A7 第 5、6 项圈出了现有字标与插画卡加立体骰的组合。W16 已确定卡牌位置并批准使用 W13 模板。本稿把新增的绘制空间留在这组物件下方。[A7 标注图](../../proposals/img/2026-11-16-art/A7-00-menu.jpg) · [美术提案 A4](../../proposals/2026-11-16-art-experience.md) · [W16 主菜单布局与 Q2](SCREENS_LAYOUT.md)

| 待定 | 推荐方案 | 另一可行方案与代价 |
| --- | --- | --- |
| M1 主体与构图 | A，浅托盘。盘沿从两侧和近侧托住四张牌及三颗骰子。牌面保持直立展开，实际位置见 §2 | B，平铺一张边角折起的桌垫。主题也用同一种物件，各风格靠印刷和包边变化。轻、平，较难让前后排读成一组 |
| M2 六套风格如何统一 | A，保持同一轮廓、相近的可见盘沿与上左侧入光，各套改变材质和绘法。静态底图由 artgen 画，四张牌、三颗骰子、字标由引擎组合 | B，各套独立设计外轮廓，仍需覆盖同一锚点范围。风格差异更强，六套各要解决卡角、盘沿与骰子的间距 |

建议 M1、M2 都选 A。确认此构图仅启动默认风格样例；签署实机样例后再开展其他五张。没有新增玩家文字。

## 3 六张怎么画

主体句为“一只宽而浅的桌上托盘，近侧盘沿略低，远侧两个角轻轻向内收，盘内留出摆放卡牌和骰子的整片空面”。六套都画这一只空盘；物件内没有骰点、牌、文字、按钮、金币、人物或额外奖励图案。各风格的材质说明来自现有风格套件，主体句和功能性区域分别记录。交付的六张是六种画法的盘；在菜单上呈现的成品还包括真正的四张牌与三颗骰子。

| 风格 | 盘面的处理 | 实机复核要点 |
| --- | --- | --- |
| 默认 | 石油青桌上的压印纸板、克制的墨线，近沿有一段可见硬边投影 | 纸色与字标纸、卡框分开，前沿低于骰子的视觉重量 |
| 瑞士现代主义 | 暖纸、折板与黑色规则线，边上只留小面积印色 | 黑线不接进卡片框，红色不形成第二个主按钮 |
| 唐三彩陶坊 | 低口陶盘，侧边露釉层、盘内收住高光 | 盘沿的釉色不会把前排陶瓷骰湮没 |
| 爆彩连环漫画 | 烫印般的轮廓，网点集中在盘沿阴影 | 骰子背后不出现射线尖端、点阵或新气泡 |
| 黑金装饰艺术 | 黑漆面，窄金边与少量对称的转角 | 深色面与背景有轮廓差，金饰不比右侧主按钮更醒目 |
| 彩绘玻璃 | 暗色承托面，彩色小玻璃和铅条集中在外围 | 分格线不穿过牌面、骰点或字标，保留桌面权重 |

## 4 默认黄金样例与推广

1. 先等 W16 主菜单的字标纸面、卡模和按钮可在实际窗口重现。与该版本留一张同布局的无底图对照。图稿阶段可先核对 A7、W16 版式与六套锚点，不需为 W17 改 W16 布局。
2. 用 `tools/art_gen/artgen.py` 及版本锁定的风格包。先验证默认风格锚点，保存 job、输入图角色与 SHA、调用记录、原始透明 PNG 及最终导出。按批准的主体独立生成空盘。现工具的默认措辞是单体卡牌插画，六个 kit 都只有 `illustration` 类别；试制优先用此类生成独立物件，按 alpha 裁边后等比放入 §2 的横框。原图若形状太高或出现完整卡牌框，退回重画。若必须引入横幅类别或改变风格包，单独记录并取得相应批准。全屏菜单拼图不作生图输入。[生成工具](../../../tools/art_gen/artgen.py) · [项目美术流程](../../art/AI_ART_PIPELINE.md)
3. 保留原始 PNG、可重放的裁切/定位参数和透明导出件。最终合成仍可独立调整底图、四张牌和三颗骰子。透明外留足画布，近侧边缘没有被切断；色轮廓放在各自的风格背景上检查透明漏边。源图在实机最大显示尺寸下能支持所选裁切，记录原像素尺寸与显示尺寸。
4. 默认样例提交无/有存档实机截屏及局部细节，附一张相同种子、相同布局的开/关底图对照。用户签署的是这一组合的实机画面。通过后沿用主体、盘沿轮廓与运行时锚点制作五套，各自使用本风格的锚点；已签默认图可作**主体与轮廓参照**，其画法不进入其他风格的风格参考。逐张验证后再打包。
