# v0.71 Codex 开发任务卡

这是现有 Unity 项目的表现层改造。阅读 ART_BRIEF.md 与 V071_PLAN.md 后按顺序执行，具体文件名映射到现有工程。以下场景和 Prefab 名为建议职责，不是已交付资源。

## 任务 1 识别工程并制作首批素材

输入：现有工程、两张 reference 图、STYLE_TOKENS.json、已有规则配置。

读取 UI 框架、渲染管线、字体、卡牌 Prefab 和骰子面序。记录现有资源中能保留的部分。使用 imagegen 与 PROMPTS.md 的参考图方法生成插画；几何图标、点阵与九宫格资源用确定性绘制。按完整方案 A01—A18 制作小套素材。

可见结果：桌布、无字卡框、按钮表面、三张控制器插画、一张道具插画和共用图标可供引擎接入。透明楼梯插画可以先用于组件展示；真实控制器 ID 从现有配置解析。

## 任务 2 共用 UI 组件

输入：任务 1 素材、现有 Prefab、ART_BRIEF.md。

按现有框架使用 unity:ui-ugui 或 unity:ui-uitk。将主题配置映射到工程已有样式系统；不另起并行主题体系。更新按钮、控制器卡、InfoStrip、DiceSlot、DetailPanel。分离插画、文字、徽记、附魔和选中层。保留已有数据绑定和交互。

可见结果：ArtStyleLab 中出现真实插画卡、主次按钮、信息条、锁章和一套统一字体；截图能读出三个表面层级。

## 任务 3 骰子和完整对局样板

输入：Blender 5.2、现有模型导入管线、任务 2 组件、母版图。

编写可重跑建模脚本，保存母版 blend 与现有格式的导出模型。身体、点数与强化层分开，保留面序映射。进入 Unity 调统一相机、材质、接触阴影，完成三池骰加两锁骰的代表状态。投掷、锁定、触发和计分复用共用动效配置，不改变 RNG 或结算。

可见结果：一张对局实机图、一段 10—15 秒实际操作录屏。只针对最显眼的构图、光影或动效差距继续改动。

## 任务 4 页面迁移

输入：完整对局样板、共用组件、商店衍生图、现有各页面。

顺序：商店、手册和详情、选关、结算、主菜单、设置。相同卡框、按钮、字体、阴影和交互状态复用原组件。商品数量变化时调整货架排布，保留五页签和真实购买状态。手册条目改为薄列表，规则骰子示例由程序排布。

可见结果：对局、商店、手册并排时属于同一套游戏界面，其余页面继承相同组件。

## 任务 5 小批次扩展内容

输入：现有 71 项内容索引、已完成插画样件、统一附魔和动效配置。

每批补 4—6 项图片，保留稳定 ID 与素材路径；只替换主题插画与数据。附魔使用既有共用层。按项目加载方式整理图集，删除已被替换的临时素材引用。仅解决本次改造引入的具体显示或绑定问题。

可见结果：实际运行界面使用正式图像与共用组件，剩余待制作项有短的路径或状态记录。

## 总任务提示词

请按 v0.71 方案改造当前 Unity 项目的表现层。先读取真实工程，沿用现有 UI 框架、渲染管线和规则绑定。对局母版是统一视觉方向，商店图是同风格衍生示例，主题参数是表现层起点。先做真实素材、共用组件和 ArtStyleLab，再迁移完整界面。使用对应 Unity skill 与可用编辑器连接；图像生成使用母版参考和局部修改。3D 骰子从 Blender 母模型派生，在 Unity 中调灯光和材质。每阶段展示可见结果，集中修正最大的三处差距。保留 p0.6.0、schema 4、物品 ID、价格、锁定规则、排序与结算。此次任务以素材真实接入可操作界面为完成形态。
