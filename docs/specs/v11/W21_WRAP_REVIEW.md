# W21 卡面断行与词表复核

依据为 2026-11-22 批准的 [字体与断行方案](FONTS_WRAP.md) 第 8 节。词表版本 1 随游戏启动载入，适用于配置里的 184 张卡、39 个首领效果、6 种战利品以及选面说明。

## 词表决定

逐项核对草稿的 266 词和实际语料，移除 44 个没有出现的词。补入 35 个游戏中实际出现的词，包括机制用语“减半、封印、复制品、同点骰、纯色骰、镀金骰”，以及“排列、对称、重新、删除、另外”等普通词。最终 257 词均出现在 229 条配置短文和 31 条选面例句的合集中。词表保护重叠词，如“正中间”的“正中”和“中间”。数字、范围、比例变化、中文量词是独立规则，可直接识别新的数字。

复核了报告里出现的 301 种非标点断点。比如“同一｜点数”是两个词的边界，“牌型｜与上次提交”可断；“从｜×1起”在无法同时满足最少行数和介词依附时允许使用。“每通过一个首领关，若永久骰未满……”与“……权重+1（更容易掷出）。”只在默认与唐三彩最窄的 7 张桌面栏各有一处词内换行，沿用规格的两条例外。

## 断行矩阵

在独立 .NET/Mono 宿主中编译与游戏相同的 `LineBreak21.cs`、与 EditMode 相同的 `V21WrapMatrix.cs`，按本机 Noto Sans CJK SC Regular 字宽测量，共 11,676 个文本版式。11,394 个得到排版，另有 282 个货品短文在所测二行上限内无解，最终是否显示由实机高度与 TMP 兜底决定。在已排版的样本中，原文、行宽、标点、末行孤字检查均无问题，只有上述 4 个词内换行版式。

## 复现与证据

- Unity EditMode 测试 `DiceCraft.Tests.V21WrapTests` 用已导入的字体度量，六套逐条结果写在 `artifacts/cache/v11/w21/wrap/layouts.tsv`。运行独立的 Python 检查 `python tools/v21_linebreak_words.py --layouts artifacts/cache/v11/w21/wrap/layouts.tsv` 可生成逐条断点清单。该工具也检查词表的版本、格式和死条目。
- 本轮宿主结果和断点清单位于 `artifacts/cache/v11/w21/wrap-managed/`。Python 词表及报告工具定向测试 2/2 通过。实机短文完整性、字号、字形出框、实际二次换行，以及 Unity 和人工签署状态由协调者在工作包验收记录中汇总。
