# W21 标题字体与短文断行的验证记录

输入为 `2fb2b08d` 和已批准的 [FONTS_WRAP](FONTS_WRAP.md)。首先验证唐三彩，其他三款标题字体待 FW-16 签署。

| 检查 | 改动与原因 |
| --- | --- |
| Art07CardReadability，卡牌短文 | 配置短文与显示文本比较时去掉版式插入的换行。对高卡、带价格的货品行另核对断行器输出及 TMP 实际行数。原有可见字形数量、透明度、边界、完整文字和裁切断言保留。 |
| PLAY_V14_E1 | 全部六套风格分别测 100%、150%，购买与最长禁购理由。保留实际卡名、插画下限统计、短文与价格碰撞检查和最小高度测量。 |
| W14CheckTexts 与 PLAY_V14_SH08 | 货架短文逐字对照配置，同时核对断行与绘制行数。选面提示、预览、原因、价格在与原文或前后缀比较时忽略布局换行。 |
| V21WrapTests | 从生产词表、实际文案与各风格的卡面布局检查禁断点、量词数字、标点、末行、优先顺序与有限宽高下的例外。 |
| V21TitleFontAssetTests、V21ThemeFontsTests | 检查唐三彩字体的静态图集、源与回落、粗体覆盖，以及缺字体或未配置时的行为。 |
| PLAY_V21_FW12、PLAY_V21_FW16 | 通过实际卡面画廊检查断行与字框，并在真实 GameView 中分屏检查唐三彩角色、回落字形、对比、字号、墨迹位置和四个场景的截图。 |
