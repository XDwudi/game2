# v0.71 共用美术说明

本文件是项目美术任务说明，不是需要安装的 SKILL。先读此页与 references/battle_master_v071.png，再开始具体任务。完整方案见 V071_PLAN.md，任务顺序见 TASKS.md。

## 核心方向

复古印刷骰桌。深青毛毡、奶油厚纸、深墨轮廓、大轮廓限色插画、温润陶瓷骰子、清楚的中文。2D 插画采用高清印刷风；3D 骰子保留柔和高光与接触阴影。避免给整屏套像素滤镜。参考图定质感与构图，主题配置定工程中的共用参数，实际规则数据定文字、状态和结果。

## 制作顺序

先做小套真实素材，再做 ArtStyleLab 和完整对局样板，随后迁移商店、手册与其他页面。卡框、按钮、字体、阴影和动作由同一组组件提供。插画扩充每批 4—6 张，引用同一母版与已有样件。

## 图像与文字分工

卡面主体使用真实插画，主题小符号仅用于状态和分类。图像不含卡名、价格、倍率或规则点阵；这些交给引擎。标题字标可以是固定图形。controller_stairs_candidate_v071.png 有透明通道，是可用于接入的插画样件；尚未在用户工程验证。母版中的示例卡名、附魔和状态不构成玩法修改。

## 统一样式

只有动作按钮有明显按压侧边。信息条和空槽低对比、薄边，纸卡有短影和完整插画。色板读 STYLE_TOKENS.json。正文 24、说明 20、按钮 26、标题 36 为 1920×1080 起点；中文不以整屏降采样变成像素字。左上主光，阴影向右下。纸纹和桌布保持安静，不覆盖正文。

## 骰子与附魔

所有骰子从同一 Blender 母模型派生，沿用现有面序；点数、面色、黄金面和状态分开。颜色读取实际数据，不能永久烘焙 1 与 4 为红色。控制器基础插画不随附魔重画；稀有度、附魔徽记、触发光各有独立层。

## 工程落地

沿用现有 UI 框架和渲染管线。uGUI 使用 unity:ui-ugui；UI Toolkit 使用 unity:ui-uitk。Unity CLI 或已有编辑器连接负责实际接入。不要凭空假定已安装工具。没有连接时生成可本地执行的编辑器脚本，不把网页截图当作 Unity 成果。

## 反馈方式

看母版与样件、看 Unity 对局截图和短录屏、看跨界面并排图。每次改最大的三处差距。缺素材继续生产素材，组件复用稳定后连续推进。沿用 p0.6.0 规则、schema 4、既有物品 ID 和价格，不因美术更改结算或存档。
