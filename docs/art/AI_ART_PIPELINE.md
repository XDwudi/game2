# AI 美术生产入口

2026-11-08；面向当前 v0.71 骰子构筑项目。此文把现有标准变成可执行工作流，未另设美术评分或降低质量预算。当前实现/验收以 [STATE](../STATE.md) 为准。

## 结论与当前缺口

采用 **同一视觉母版 + 参考图生成/局部编辑 + 原生源整理 + 共享引擎组件 + 实机对照**。质量来自每件资源的完整制作闭环；增加模型或生成数量本身不能证明风格一致。

项目已有 C48/C29/C03/I07 四张插画、确定性公共表面、Blender 陶瓷骰子母版和 UiKit/ArtStyleLab。67 项仍为旧图标，正式风格标杆与整版验收尚未完成。详细证据和实际抽样见 [项目审计](../research/AI_ART_PROJECT_AUDIT.md)。v071 已将旧像素媒介改为高清限色印刷，不要用旧 64px 网格与 Point 规则约束全部新资源。

## 风格一致的具体执行

1. **冻结本批输入。** 使用 [轻量制作记录](../../templates/AI_ART_JOB.md)，引用任务、内容 ID、ART_SPEC、母版、已有样件和对应组件。现有插画记录格式继续复用，不迁移或重写历史清单。
2. **区分参考角色。** 母版约束材质、色块、轮廓与整体层次；已有插画约束单件画法；目标图承载本次编辑；实际游戏图约束功能布局。规则信息从配置读取。
3. **保持固定部分。** 同一参考包、同一裁切位置、同一纸框和状态层；只变本次主体或缺陷。不要让主菜单、商店、对局各自产生一套画法。提示词引用现有风格段，不靠堆“精致”形容词。
4. **按资产分工。** 主题图使用生图/局部编辑；精确几何用脚本；3D 用已验证母模型。附魔/数值/价格/文字继续实时分层。透明 PNG 不自带卡框或全屏界面。
5. **逐层看结果。** 原尺寸检查结构与边缘；放在纸色/深桌面看脏边；在实际卡面/紧凑卡/详情看识别度；同类并排看漂移；最后查看真实运行。只修改明确问题，并重验影响范围。
6. **复用而后扩展。** 新资源类型先做一个完整样例；已有人工确认方向内按授权小批自主制作。沿原规格每批4—6项，不预先自动生成剩余67项。三处自然对照点及人工权责仍以 ART_SPEC §12、QUALITY_GATES 为准。

不要将“3—5 主色”“70%—85%主体面积”等制作建议变成 RGB 数量、像素占比的自动硬门槛。抗锯齿、印刷颗粒和光照有合理变化；需比较角色、主次和可读性。

## 哪些检查能自动完成

| 层 | 检查方法 | 能证明 / 不能证明 |
|---|---|---|
| 文件完整性 | 检查器核 SHA、声明尺寸、PNG解码、alpha、非空、引用路径；按需比对运行副本和.meta存在 | 能检出损坏/失配/缺失；不能证明背景视觉纯净、许可有效或Unity导入正确 |
| 原生源可继续编辑 | 按实际类型打开/保存/重开KRA或blend；图层/依赖/导出检查 | PNG原图不能冒充手绘分层源；KRA容器存在不能冒充Krita原生重开 |
| 引擎集成 | 检查实际 TextureImporter、GUID/引用、压缩/sRGB/过滤/裁切、九宫格和运行绑定 | .meta存在不是导入设置或可见性已验；先用既有测试和录制工具 |
| 风格/可读性 | 已认可参考与本批在同一真实镜头、背景、尺寸下并排 | 具体视觉结论需看图；自动相似度或AI自评不签艺术认可 |
| 动态/性能/平台 | 按任务的1080p、720p/150%、容量与平台场景运行适用检查 | 静态图不证明交互/节奏，Windows不证明Mac或移动端 |

现有四图的实际命令（输出选一个未存在的新文件）：

```powershell
python tools/art_asset_audit.py --manifest ArtSource/Art071/Illustrations/manifest.json --require-alpha --runtime-dir DicePrototype/Assets/Art/Art071/Illustrations --output evidence/ai-art-pipeline/illustrations-new-run.json
```

## 当前 Image2 能力与其他工具

内置 imagegen 本会话已实际调用，并把 I07 主题的独立透明候选保存在 [试验目录](../../ArtSource/AIConcepts/imagegen-probe-20261108/manifest.json)。完整提示词和参考/输出身份同目录；没有把它导入游戏或替换原图。官方描述内置模型为 `gpt-image-2`；工具没有提供实际模型快照字段。[官方图像能力](https://learn.chatgpt.com/docs/image-generation)

目前无需新增付费服务即可进行前期概念。独立 API/CLI 路线需要 API Key/账户权限，当前未调用。内置工具参数与特定 API 模型参数应分开核对，不能混用透明背景能力。

后续确有反复局部修图、构图控制或批量风格漂移时，优先试 **Krita AI Diffusion + ComfyUI/ControlNet**；需核实本机 Krita/GPU/显存或云额度、插件与模型版本及来源。参考集经人工认可并稳定后才考虑风格 LoRA。Blender MCP 是方便交互的可选连接；复杂装饰物可单独评估图生3D。精确骰体继续复用 Blender 母版。

第一方资料、候选技能、许可与升级条件见 [研究报告](../research/AI_ART_TOOLS_RESEARCH.md)。本次没有下载第三方技能源码/模型权重、安装Comfy节点或宣称这些服务已接通；采纳的是经项目适配的流程与本地技能。

## 交付和变更

原稿/失败稿不覆盖；文件名以稳定ID和修订号区分。把源、导出、运行件、参考与实际审查对应到内容哈希；新参考或新材质使相关旧证据失效。保留生成原图以及真实编辑历史，不杜撰seed/模型/批准记录。

实施者提交 REVIEW，由独立复核给出规格符合与制作质量结论。普通重复制作不逐资产索取批准，风格标杆与量产阶段仍由用户决定。参见 [本次任务](../tasks/AI-ART-PIPELINE.md) 及 [质量规则](../QUALITY_GATES.md)。
