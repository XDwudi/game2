骰子构筑 P0 v0.4 — Windows 原型

请完整解压本压缩包，再双击 DiceCraft.exe。不要只复制exe；旁边的Data目录和DLL是运行所需文件。本原型不需要安装Unity或Blender。

建议先点击“练习：锁定与得分”。练习不覆盖正式挑战。新挑战可留空种子随机开始，或输入0至4294967295的十进制整数复现。

鼠标点击骰子选择待锁，E确认锁定。确认后本手不能直接解锁。
空格投掷未锁骰；1–9、0也可切换待锁。
拖动已锁骰交换顺序；Enter提交。未处理的待锁会阻止投掷/提交。
右键查看骰子六面与概率；点击计分明细查看逐步计算。
过关后进入商店，选择商品及合法目标，再前往下一关。
Esc打开设置或关闭弹窗；支持快动画、减少动态、音量和跳过。

每次有效操作先保存结果，再播放表现。退出后从主菜单继续即可恢复。
存档通常位于：%USERPROFILE%\AppData\LocalLow\XDwudi\DiceCraft P0
写盘失败时界面会停止后续操作；恢复写入条件后点击重试，不会重抽结果。
如需保留多个挑战，请在启动新挑战前自行备份该目录。

这是原型测试版，尚无真人体验或移动端验收结论。具体技术验收状态、已知限制、测试与源工程：
https://github.com/XDwudi/game2
仓库 docs/STATE.md 为最新状态；build-manifest.json 标识本包实际文件哈希。
